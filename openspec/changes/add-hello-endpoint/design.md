# 设计：add-hello-endpoint

## 方案概述

使用 Express.js 创建一个最简 HTTP 服务器，注册 `GET /hello` 路由，返回固定 JSON 响应。

## 设计决策

### 决策 1：技术选型

**选择**：Express.js + Jest
**理由**：Express 是 Node.js 最主流的 Web 框架，Jest 是最主流的测试框架。两者配合成熟稳定。

### 决策 2：路由注册方式

**选择**：在 `app.js` 中直接注册路由 `app.get('/hello', handler)`
**理由**：只有一个端点，不需要拆分路由文件。保持最简结构。

### 决策 3：响应格式

**选择**：`{ "message": "你好，世界！" }`，Content-Type 为 `application/json`
**理由**：固定 JSON 对象，使用框架的 `res.json()` 自动设置正确 Content-Type。

### 决策 4：不使用中间件

**选择**：该端点不挂载任何中间件（无鉴权、无限流、无日志）
**理由**：这是健康检查风格的端点，保持最简确保始终可响应。

## 风险与取舍

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 端点路径与未来路由冲突 | 低 | 中 | `/hello` 是非业务路径，冲突概率低 |
| 缺少错误处理 | 低 | 低 | 静态响应不会抛错，无需 try-catch |
