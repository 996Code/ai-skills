# 提案：add-hello-endpoint

## 为什么需要

项目当前没有任何 HTTP 端点。需要一个最简单的 `GET /hello` 端点，用于：
1. 验证服务器是否正常运行
2. 作为后续端点开发的参考模式
3. 验证 `/ai:*` 工作流命令的完整链路

## 变更内容

- 新增 `GET /hello` 端点，返回 JSON 格式的问候语
- 新增对应的单元测试

## 能力范围

### 新增能力
- `hello-endpoint`：问候端点，返回固定 JSON 响应

### 修改能力
（无，这是全新能力）

## 影响范围

- 新增路由文件
- 新增测试文件
- 需要安装 express 和 jest 依赖
