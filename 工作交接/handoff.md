请按以下步骤生成交接班记录并提交：

## 第 1 步：确认今日工作

```bash
# 获取今天的日期
date +%Y-%m-%d

# 获取今天的提交
git log --oneline --since="today" --format="%h %ai %s"
```

如果没有今天的提交，扩大范围查找最近一次提交以来的变化：

```bash
git diff --stat
git status --short
```

## 第 2 步：生成/更新今日会话记录

根据今天的提交和代码改动，生成或更新 `docs/dev-session-YYYY-MM-DD.md`（YYYY-MM-DD 替换为今天的日期）。

格式参考已有会话记录，包含：
- **提交记录**：列出今天所有 commit
- **改动概要**：按模块分类的改动表格
- **关键修复**：重要的 bug fix 和优化说明
- **踩坑记录**：遇到的技术问题和解决方案
- **待完成**：未完成的工作项

如果文件已存在，**追加**下午/晚间的工作内容（不要覆盖已有内容）。

## 第 3 步：更新进度文档

如果项目中存在 `PROGRESS.md` 或类似进度追踪文档，根据最新完成的工作更新：
- 将已完成项从"待开发"移到"已完成"
- 添加新发现的需要做的工作项
- 更新日期

## 第 4 步：提交并推送

```bash
# 添加文档改动
git add docs/ PROGRESS.md 2>/dev/null || true

# 提交
git commit -m "docs: 更新开发会话记录和进度"

# 推送
git push
```

## 第 5 步：输出交接摘要

用简洁的中文输出：

1. **今日完成**：一句话总结
2. **文档更新**：列出更新的文件
3. **Git 状态**：确认已推送
4. **下次接手**：建议下一步做什么

最后输出 "交接完成。" 并等待确认。
