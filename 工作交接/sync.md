请按以下步骤加载项目上下文：

## 第 1 步：从远程同步代码

```bash
git pull
```

如果有冲突，提示用户手动解决后再继续。

## 第 2 步：读取项目文档

按优先级读取以下文件（跳过不存在的）：

1. `CLAUDE.md` — 项目指令（如果存在必读）
2. `README.md` — 项目说明
3. `PROGRESS.md` 或类似进度文档 — 如果存在则读取
4. `docs/` 目录下最新的开发记录（如有）

## 第 3 步：检查 Git 状态

```bash
git log --oneline -15 --format="%h %ai %s"
git status --short
```

## 第 4 步：输出上下文摘要

用简洁的中文输出：

1. **项目状态**：一句话总结
2. **最近工作**：最近 3 次提交做了什么
3. **待办事项**：从进度文档中提取待完成项（如有）
4. **工作树状态**：是否有未提交的改动

最后输出 "上下文加载完成，可以开始工作。" 并等待指令。
