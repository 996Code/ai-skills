# 篇幅模式与文件结构

> SKILL.md篇幅相关详细规则，创建项目时按需加载。

## 短篇（1万字以内）

```
novels/[小说名]/
├── 简介.txt
├── planning/
│   ├── creative-brief.md    # 创意档案
│   ├── bible.md             # 合并圣经（世界观+角色+伏笔+时间线+信息差）
│   └── outline.md           # 合并大纲（总纲+章纲）
├── text/
│   └── [小说名].txt          # 正文（单文件txt）
└── reviews/
    └── review.md             # 审校报告（可选）
```

- bible/outline合并为单文件，角色卡合并在bible.md
- 正文写在一个txt里，用`第X章：[章节名]`分隔
- 允许一次性完成初稿，不逐章中断
- 审校自审，不用delegate_task
- 大纲验证精简为3项：特定性测试、伏笔覆盖、角色弧线
- 精修不机械删10%，标注冗余段落定向精简

## 中篇（1-5万字）

```
novels/[小说名]/
├── 简介.txt
├── planning/
│   ├── creative-brief.md
│   ├── bible.md              # 合并圣经
│   └── outline.md            # 合并大纲
├── text/
│   ├── 第1章：[章节名].txt
│   ├── 第2章：[章节名].txt
│   └── ...
├── summaries/
│   └── ch001-010.md          # 章节摘要（每10章一个文件）
└── reviews/
    ├── per-chapter/                    # 逐章审查
    │   ├── ch-001/
    │   │   ├── 逻辑侦探.md
    │   │   ├── 情感猎手.md
    │   │   ├── 风格鉴定师.md
    │   │   ├── 结构建筑师.md
    │   │   ├── 世界观守门人.md
    │   │   └── review.md
    │   └── ch-002/
    │       └── ...
    ├── patterns.md                     # 系统性问题模式
    └── final/                          # 全书终审
        └── review.md
```

- 角色卡、伏笔链、信息差矩阵不能省略（合并在bible.md中）
- 执笔必须逐章推进，不要一口气写完
- 每章写完做轻量校验：信息差/伏笔/角色语言

## 长篇（50万字起步）

> ⚡ 写长篇时，加载 `references/long-form.md` 获取完整指南（L1-L8金手指/黄金三章/爽点/断章/防崩/角色/打戏/伏笔）。

**⚠️ 用户硬性规则：长篇起步50万字。** 不写10万字、20万字的"长篇"——要么短篇/中篇，要么50万字起步。50万字约150-200章（每章2500-3500字），5-8卷结构。

### 多女主身材描写（男频网文专项）

- 50万字长篇多女主是标配，每个女主必须有差异化的身材锚点
- 锚点不是露骨描写，是1-2个标志性细节+特定场景下的自然呈现
- 四种典型锚点：冰山型/御姐型/温柔型/妖精型
- **频率控制**：同一女主的身材锚点每5章最多出现1次
- **场景绑定**：身材描写必须绑定功能场景，纯写身材没有叙事功能=删

### 暧昧/露骨情节尺度（用户偏好）

- 尺度定位：不涉黄但氛围拉满，类似《庆余年》尺度
- 写法：轻撩+暗示为主，靠感官描写和心理描写制造张力，不写器官细节
- 场景类型：酒后失态、意外撞见、肢体接触、眼神交锋、暧昧对话
- **核心技法**：写"未完成"比写"完成"更有张力——停在即将发生的瞬间

### 宿舍/日常烟火气（男频校园长篇专项）

- 宿舍日常是读者代入感和"喘息感"的核心来源，不是注水
- 典型场景：打游戏、食堂抢菜、修电脑、熄灯后夜聊、室友八卦
- 写法要点：对话自然拌嘴+每个人有辨识度
- **功能**：①缓解紧张节奏 ②展现主角"融入当下"的心理转变 ③为兄弟团后续弧线打底
- 频率：每3-5章至少1段宿舍日常
