# 跨章诊断方法论

> 批量交付（连写N章后一起交付）时的跨章一致性自审清单。
> 单章审查看不到的问题，只有跨章才能暴露。

## 使用时机

- 每写完 3 章做一次轻量检查（`python3 novel_check.py --slide`）
- 批量交付前做一次完整检查（逐项过本清单）
- 审校阶段必做

---

## 检查清单

### 1. 时间线连续性

**问题**：日期/天数/季节前后矛盾。

```bash
grep -rn '第.*天\|月\|周[一二三四五六日末]' text/
```

**典型问题**：
- 第3章写"入学第三天"，第5章突然变成"第一周"——中间跳了4天没交代
- 前文写"九月"，后文出现"蝉鸣"（蝉在七月）

---

### 2. 角色外貌一致性

**问题**：发型/身高/特征描写跨章不统一。

```bash
grep -rn '长发\|短发\|头发\|眼睛\|身高\|马尾\|刘海' text/
```

**典型问题**：
- 第1章写"齐肩短发"，第7章变成"甩了甩长发"
- 角色A的眼睛从"深棕色"变成"琥珀色"

---

### 3. 前世记忆泄露

**问题**：主角在当前身份下说出了只有前世才知道的细节。

**检查方法**：对每段主角的对话/内心独白追问——"他怎么知道的？"

**典型问题**：
- 主角穿越到大学，却精确知道某教授的研究方向（前世记忆未圆场）
- 主角对配角说出"你家住在XX路"这种只有前世才知道的信息

---

### 4. 物理设定一致性

**问题**：宿舍/教室/校园等空间描写跨章矛盾。

```bash
grep -rn '人间\|上铺\|下铺\|铁架\|上床下桌\|阳台\|窗' text/
```

**典型问题**：
- 第2章写"四人寝上床下桌"，第6章变成"六人寝上下铺"
- 角色从"靠门的床位"突然变成"靠窗的床位"

---

### 5. 季节天气连贯性

**问题**：同一时间段内天气/植物/温度描写不一致。

```bash
grep -rn '月\|蝉\|叶\|凉\|暖\|雪\|风\|雨\|晴' text/
```

**典型问题**：
- 开学季（九月）却写"烈日当头蝉鸣不断"（九月初蝉已少见）
- 同一天内上午"阳光灿烂"下午"秋风萧瑟"

---

### 6. 伏笔埋收对应

**问题**：前面埋的伏笔后面没有回收，或回收时与埋设不一致。

**检查方法**：
1. 打开 outline 查看伏笔计划
2. grep 伏笔关键词确认每条伏笔的埋设章和回收章

```bash
# 示例：追踪某个伏笔关键词
grep -rn '关键词' text/
```

**典型问题**：
- 大纲计划第3章埋伏笔、第8章收，但第8章写的时候忘了
- 伏笔回收时的细节与埋设时矛盾（如物品颜色变了）

---

### 7. 孤儿设定

**问题**：仅出现1次的设定性描述，既没有呼应也没有服务情节。

**检查方法**：grep 每个设定性关键词，出现次数=1 的需要判断。

```bash
# 找只出现一次的设定性词
for word in "关键词1" "关键词2"; do echo "=== $word ==="; grep -rn "$word" text/; done
```

**判定**：
- 如果是丰富背景的闲笔 → 保留（好的留白）
- 如果是暗示后续情节的伏笔 → 确认有回收计划
- 如果是写的时候随手加的 → 删除（避免读者期待落空）

---

### 8. 设定修改残留

**问题**：改了某个设定后，旧版本的描写没有完全清理。

**检查方法**：确认修改后 grep 所有相关关键词。

```bash
# 例：改了角色名后
grep -rn '旧名\|原名' text/
```

**典型问题**：
- 角色从"李明"改名"李明远"后，某处还写着"李明"
- 设定从"南方城市"改成"北方城市"后，某处还有"湿润的空气"

---

### 9. 装傻悖论

**问题**：主角先展示了高超能力，后文又装不知道基础概念。

**检查方法**：追踪主角在每章展现的能力水平线，确认只升不降。

**典型问题**：
- 第5章主角展示了专业级编程能力
- 第7章主角面对基础代码"一脸茫然"——除非有合理的伪装动机

---

### 10. 女主登场锚点

**问题**：重要女角色首次出场缺少多感官锚点。

**检查方法**：找到每个重要女角色的首次出场章，确认有 ≥3 种感官描写。

```bash
# 找角色首次出场
grep -rn '苏晚晴\|叶霜\|秦岚\|沈灵' text/ | head -5
```

**首次出场至少需要**：
- 视觉锚点（外貌/衣着/动作）
- 听觉锚点（声音/语气）
- 嗅觉/触觉锚点之一（气味/温度/质感）

## 自动化检查

以上部分项已由 `novel_check.py --slide` 自动覆盖：

| 自动检查项 | 窗口大小 |
|-----------|---------|
| 断章钩子重复 | 3章 |
| 比喻/意象去重 | 10章 |
| 擦边频率 | 5章 |

其余项需手动逐项检查，建议用上方 grep 命令辅助。
