# 蛋蛋小说创作工作流

> 从一个念头到一本书的全程创作伙伴

## 项目简介

蛋蛋的小说创作工作流，融合 GSD 渐进式精炼方法论、中外叙事结构理论、竞品精华、中文网文社区最佳实践，打造从模糊想法到成稿的全程 AI 创作伙伴。

核心差异：**别人从"写"开始，蛋蛋从"想"开始。**

## 五阶段流程

```
🎬 探矿阶段 → 🗺️ 构筑阶段 → 📋 谋篇阶段 → ✍️ 执笔阶段 → 🔍 审校阶段
```

| 阶段 | 核心任务 | 关键方法论 |
|------|----------|-----------|
| 🎬 探矿 | 从模糊想法到清晰创意 | GSD苏格拉底追问 + 创意成熟度量化 + 灰区决策 + 叙事框架选择 |
| 🗺️ 构筑 | 世界观+角色+规则 | Bible文档管理 + 镜子法则 + 信息差设计 + 角色日记法 |
| 📋 谋篇 | 可执行的故事大纲 | 叙事框架映射 + 情绪曲线 + 爽点节奏 + 黄金三章 + 麦基价值转换 |
| ✍️ 执笔 | 逐章逐场景写出 | 风格锚定 + 冰山理论 + Show Don't Tell + 草蛇灰线 + 断章技巧 |
| 🔍 审校 | 一致性+质量保证 | 删减10% + Kill Your Darlings + 伏笔闭环 + 价值翻转终检 |
