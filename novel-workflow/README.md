# 蛋蛋小说创作工作流

> 从一个念头到一本书的全程创作伙伴

## 项目简介

蛋蛋的小说创作工作流，融合 GSD 渐进式精炼方法论、Sudowrite/Novelcrafter 等竞品精华、中文网文社区最佳实践，打造从模糊想法到成稿的全程 AI 创作伙伴。

核心差异：**别人从"写"开始，蛋蛋从"想"开始。**

## 五阶段流程

```
🎬 探矿阶段 → 🗺️ 构筑阶段 → 📋 谋篇阶段 → ✍️ 执笔阶段 → 🔍 审校阶段
```

## 8大独特优势

1. 🎬 探矿式需求挖掘（苏格拉底追问）
2. 📊 创意成熟度量化（4维度模糊度评分）
3. 🧩 灰区决策识别（关键创作决策点）
4. 📚 Bible文档自动管理（跨阶段上下文传承）
5. 🎯 风格锚定+感官增强（中文网文优化）
6. 🛡️ 反模式防护（禁止凑合写/角色跑偏/伏笔遗忘）
7. 🔄 迭代精修闭环（AI漂移检测+一致性检查）
8. 🇨🇳 中文网文深度适配（三级大纲+CRISPE+流派理解）
