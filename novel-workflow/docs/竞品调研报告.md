## 一、海外AI小说写作工具

### 1. Sudowrite（海外最强小说AI工具）

- **官网**：sudowrite.com
- **定价**：$10-29/月
- **核心能力**：
  - Story Engine：从大纲生成完整章节
  - Describe：一键生成感官描写（视觉/听觉/触觉/嗅觉/味觉）
  - Rewrite：多风格改写
  - Shrink Ray：智能压缩/编辑
  - 风格锚定：上传参考文本模仿风格
- **弱点**：
  - 封闭生态，只能用他们的模型
  - 长篇一致性靠人工维护，没有自动机制
  - 没有需求挖掘阶段，用户得自己想清楚再输入
  - 不支持中文网文风格

### 2. Novelcrafter（最灵活的专业工具）

- **官网**：novelcrafter.com
- **定价**：$8-20/月 + API费用
- **核心能力**：
  - Codex系统：角色/地点/传说结构化管理（类似Bible文档）
  - 场景级写作：逐场景推进，每个场景可注入上下文
  - 多模型后端：Claude/GPT/本地模型随意切换
  - 章节摘要链：自动维护前文摘要
- **弱点**：
  - 需要API key，门槛高
  - 没有需求挖掘/讨论阶段
  - 规划靠用户自己，工具只管写
  - 学习曲线陡峭

### 3. NovelAI（隐私+二次元向）

- **官网**：novelai.net
- **定价**：$10-25/月
- **核心能力**：
  - Lorebook：世界观词条自动注入（关键词触发相关设定）
  - 模型微调：可训练自己的风格
  - 图文一体：AI生成配图
- **弱点**：
  - 上下文窗口小
  - 规划工具弱
  - 偏二次元/日式风格

### 4. 其他海外工具

## 二、中文AI小说写作工具

### 1. 彩云小梦（中文最早）

- **官网**：dreamily.ai
- **核心能力**：
  - 中文续写，多风格选择（古风/玄幻/都市）
  - 协作写作模式
- **弱点**：续写为主，没有规划能力；长篇一致性差

### 2. 笔神AI（中文最专业）

- **核心能力**：
  - 角色管理、大纲生成、世界观构建
  - 长篇连贯性较好
  - 网文类型模板
- **弱点**：模板化灵活性差；没有深度需求挖掘

### 3. 蛙蛙写作（最易上手）

- **核心能力**：
  - 预设网文流派模板（赘婿流/系统流/重生流）

- **弱点**：高度模板化，同质化严重

  - 基于海量网文训练的专用大模型
  - 网文风格最贴合

## 四、AI小说写作方法论

### A. 层级分解法（最主流）

1. 概念/前提生成 → 世界观构建 → 角色开发 → 剧情大纲 → 逐章起草 → 修订 → 润色

核心原则：AI在窄而具体的任务上表现最好，不要笼统地"写一章"。

### B. 雪花法（AI改编版）

一句话→一段→一页→一章，逐层膨胀，每层人工把关。

### C. 上下文管理法

Bible文档 + 滚动摘要 + 分段生成 + 一致性检查 + 定期全本审校

### D. 导演-演员法（中文圈）

人类=导演（定方向、做决策），AI=演员（执行、生成、填充细节）

### E. 迭代精修法

生成→审查→修改→再生成，循环直到满意，最后人工统一声线

### F. 中文四阶段法

设定→细纲→写作→审校，核心"分段生成+人工串联"

### G. CRISPE提示词框架

Capacity(角色)-Role(人设)-Insight(背景)-Statement(任务)-Personality(文风)-Experiment(迭代)

## 六、所有竞品的共同盲区

1. ❌ 没有需求挖掘阶段——假设用户已想清楚
2. ❌ 没有量化"想法成熟度"——凭感觉决定能不能开始写
3. ❌ 没有苏格拉底式追问——不会深挖"想写什么、为什么、给谁看"
4. ❌ 没有灰区决策机制——不会帮用户发现关键创作决策点
5. ❌ 没有跨阶段上下文自动传承——角色卡/伏笔靠人工维护
6. ❌ 没有反模式防护——不会阻止"先凑合写"、"角色跑偏"
7. ❌ 中文工具高度模板化——同质化严重，缺乏个性化

## 七、GSD方法论学习笔记

### GSD核心理念

- **渐进式精炼**：模糊想法→提问挖掘→灰区讨论→制定计划→执行→验证
- **思维伙伴哲学**：用户=创始人/愿景家，AI=建造者
- **量化模糊度**：4维度评分（目标清晰度35%+边界清晰度25%+约束清晰度20%+验收标准20%），≤0.20才能进入下一阶段
- **苏格拉底式提问**：追着用户的话头问，不是走检查单
- **灰区识别**：自动发现"都能走但结果不同"的决策点
- **反模式防护**：禁止模糊任务、范围偷减、"以后再说"
- **上下文传承**：每个阶段的决策自动带入下一阶段

### GSD阶段流程

```
模糊想法 → new-project → [new-milestone]
  → spec-phase (苏格拉底访谈，量化模糊度，锁定WHAT)
  → discuss-phase (灰区讨论，锁定HOW)
  → plan-phase (研究→规划→验证循环)
  → execute-phase (波浪式并行执行)
  → verify (验证验收)
```

### GSD关键技巧

- **追问技术**：追逐用户强调的，挑战模糊词（"好是什么意思？"），把抽象变具体
- **角色轮换访谈**：研究者→简化者→边界守护者→失败分析师→闭环者
- **灰区列表**：根据领域类型自动生成关键决策点
- **计划反模式**：禁止"v1"/"简化版"/"先硬编码"/"未来增强"等偷减措辞
- **特定性测试**：另一个AI实例能否无需追问就执行这个任务？

## 八、蛋蛋小说创作工作流设计思路

### 核心定位

> 蛋蛋不是帮你写小说的工具，蛋蛋是帮你把一个念头变成一本书的搭档。
> 别人从"写"开始，蛋蛋从"想"开始。

### 五阶段流程

```
🎬 探矿阶段 → 🗺️ 构筑阶段 → 📋 谋篇阶段 → ✍️ 执笔阶段 → 🔍 审校阶段
```

### 各阶段设计要点

1. **探矿阶段**（借鉴GSD spec-phase + discuss-phase）
   - 苏格拉底式需求挖掘
   - 创意成熟度量化评估（4维度）
   - 灰区决策识别与讨论
   - 产出：创意档案（核心冲突、角色动机、世界观边界、读者预期）

2. **构筑阶段**（借鉴Novelcrafter Codex + Lorebook + 中文人设卡法）
   - 世界观Bible构建
   - 角色卡系统
   - 伏笔链/时间线初始化
   - 产出：Bible文档集（世界观.md、角色卡.md、时间线.md、伏笔链.md）

3. **谋篇阶段**（借鉴GSD plan-phase + 中文三级大纲法）
   - 三级大纲：总纲→卷纲→章纲
   - 反模式防护（禁止偷减、禁止模糊）
   - 计划验证（逻辑检查、伏笔覆盖检查）
   - 产出：大纲文档集（总纲.md、卷纲.md、章纲.md）

4. **执笔阶段**（借鉴Sudowrite风格锚定 + 迭代精修法 + 导演-演员法）
   - 风格锚定（注入参考文风2-3段）
   - 分段生成（每段500-1000字，注入Bible+大纲+前文摘要）
   - 感官描写增强
   - 迭代精修循环
   - 角色一致性校验
   - 产出：章节草稿

5. **审校阶段**（借鉴上下文管理法 + AI漂移检测）
   - 一致性检查（角色/时间线/逻辑）
   - 文风统一润色
   - 伏笔闭环检查
   - 产出：终稿

### 8大独特优势

| # | 优势 | 来源 | 竞品有无 |
|---|------|------|---------|
| 1 | 探矿式需求挖掘 | GSD苏格拉底提问 | ❌ 全没有 |
| 2 | 创意成熟度量化 | GSD模糊度评分 | ❌ 全没有 |
| 3 | 灰区决策识别 | GSD灰区机制 | ❌ 全没有 |
| 4 | Bible文档自动管理 | Novelcrafter Codex + Lorebook | ⚠️ 有但不跨阶段 |
| 5 | 风格锚定+感官增强 | Sudowrite Describe | ⚠️ 有但无中文优化 |
| 6 | 反模式防护 | GSD反模式 | ❌ 全没有 |
| 7 | 迭代精修闭环 | 精品方法论+AI漂移检测 | ⚠️ 部分有 |
| 8 | 中文网文深度适配 | 中文圈四阶段法+CRISPE | ⚠️ 有但没前7项 |
