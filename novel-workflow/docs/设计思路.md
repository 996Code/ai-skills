# 蛋蛋小说创作工作流设计思路

> 创建时间：2026年5月 | 创建人：蛋蛋 | 状态：设计阶段

---

## 核心定位

> **蛋蛋不是帮你写小说的工具，蛋蛋是帮你把一个念头变成一本书的搭档。**
> 别人从"写"开始，蛋蛋从"想"开始。

---

## 五阶段流程

```
🎬 探矿阶段 → 🗺️ 构筑阶段 → 📋 谋篇阶段 → ✍️ 执笔阶段 → 🔍 审校阶段
```

### 1. 🎬 探矿阶段（Prospect）

**灵感来源**：GSD spec-phase + discuss-phase

**核心任务**：从模糊想法到清晰创意

**子步骤**：
1. **开放式倾听**：让用户自由描述想法，不做检查单式提问
2. **苏格拉底追问**：
   - 追线索——追逐用户强调的词
   - 挑战模糊词——"好是什么意思？""热血是什么样的热血？"
   - 让抽象变具体——"带我走一遍主角的一天"
   - 揭示动机——"为什么想写这个故事？想给读者什么感受？"
3. **创意成熟度量化评估**：
   - 核心冲突清晰度（35%）：主角要什么？什么在阻碍？代价是什么？
   - 角色动机明确度（25%）：为什么是这个角色？内在驱动力是什么？
   - 世界观边界清晰度（20%）：故事发生在哪？规则是什么？
   - 读者预期明确度（20%）：给谁看？想引发什么情绪？
   - 模糊度 = 1.0 - 加权平均；门槛 ≤ 0.20
4. **灰区决策识别与讨论**：
   - 叙事视角（第一人称/第三人称/全知）
   - 节奏风格（快节奏爽文/慢铺垫文学/张弛有度）
   - 结局走向（HE/BE/OE/开放式）
   - 情感基调（热血/治愈/暗黑/幽默/悲壮）
   - 结构模式（线性/多线/倒叙/环形/套娃）
5. **产出**：创意档案（核心冲突、角色动机、世界观边界、读者预期、灰区决策）

**反模式**：
- 不走检查单——追着用户的话头问
- 不审讯式提问——像朋友聊天不是面试
- 不催促——模糊度高就继续聊
- 不提前设限——不要用类型模板框住创意

---

### 2. 🗺️ 构筑阶段（Build World）

**灵感来源**：Novelcrafter Codex + NovelAI Lorebook + 中文人设卡法 + GSD上下文传承

**核心任务**：构建故事的基础设施——世界观、角色、规则

**子步骤**：
1. **世界观Bible构建**：
   - 物理规则/社会结构/历史背景/技术/魔法体系
   - 地理/势力/经济/文化
   - 约束与禁忌（什么不可能、什么不允许）
2. **角色卡系统**：
   - 基础信息（姓名/年龄/外貌/身份）
   - 内在维度（动机/恐惧/弱点/信念/秘密）
   - 关系网络（与谁什么关系、冲突点、羁绊）
   - 角色弧线（起点状态→转变触发→终点状态）
   - 语言指纹（口头禅/说话风格/习惯动作）
3. **伏笔链初始化**：
   - 预埋伏笔清单
   - 伏笔回收计划
4. **时间线初始化**：
   - 故事前史时间线
   - 故事主线时间线骨架
5. **产出**：Bible文档集（世界观.md、角色卡/、时间线.md、伏笔链.md）

**关键原则**：
- 每个角色必须有动机和弱点——没有就是纸片人
- 世界观必须有规则和边界——没有约束就没有戏剧张力
- 角色关系必须有冲突点——没有冲突就没有故事

---

### 3. 📋 谋篇阶段（Plan Story）

**灵感来源**：GSD plan-phase + 中文三级大纲法 + GSD反模式防护

**核心任务**：制定可执行的故事大纲

**子步骤**：
1. **总纲**（全书）：
   - 一句话概括
   - 核心冲突线
   - 主角弧线
   - 起承转合四幕/三幕结构
   - 卷划分与各卷主题
2. **卷纲**（每卷）：
   - 本卷核心冲突
   - 角色关系变化
   - 伏笔埋设与回收
   - 章划分与各章主题
3. **章纲**（每章）：
   - 场景列表（每章2-5个场景）
   - 每个场景：角色、冲突、情感变化、推进了什么
   - 章末钩子（让读者想继续读的东西）
   - 伏笔回收点标注
4. **大纲验证**：
   - 特定性测试：另一个AI能否仅凭章纲就写出这一章？如果不能，加细节
   - 逻辑检查：情节因果链是否成立
   - 伏笔覆盖：埋的伏笔是否都有回收计划
   - 角色弧线检查：主角是否有实质成长/变化
5. **产出**：大纲文档集（总纲.md、卷纲/、章纲/）

**反模式防护**：
- ❌ 禁止"先写个大概"——大纲必须具体到能直接执行
- ❌ 禁止"后面再说"——伏笔必须标注回收章
- ❌ 禁止范围偷减——承诺的情节点必须在大纲中体现
- ❌ 禁止无冲突章节——每章必须有推进或转折

---

### 4. ✍️ 执笔阶段（Write）

**灵感来源**：Sudowrite风格锚定 + 迭代精修法 + 导演-演员法 + 上下文管理法

**核心任务**：逐章逐场景地写出来

**子步骤**：
1. **写前准备**：
   - 加载相关Bible片段（本章涉及的角色卡+世界观设定）
   - 加载章节大纲
   - 加载前文摘要（最近3-5章的摘要）
   - 注入风格锚定文本（2-3段参考文风）
2. **分段生成**：
   - 按场景分段，每段500-1000字
   - 每段注入：角色当前状态+场景目标+情感走向
   - 感官描写增强（五感维度检查）
3. **即时校验**：
   - 角色一致性：对话风格是否符合角色卡？
   - 伏笔追踪：本章有没有应该埋/收的伏笔？
   - 情感弧线：场景情绪走向是否符合大纲？
4. **迭代精修**：
   - 生成初稿→审查问题→定向修改→再生成
   - 循环直到该场景满意
5. **章末维护**：
   - 更新角色状态（情绪/关系/能力变化）
   - 更新伏笔链（新埋/已收）
   - 生成章节摘要（供后续章节引用）
   - 更新时间线
6. **产出**：章节草稿 + 更新的Bible文档

**关键原则**：
- 不批量生成多章——每章写完必须审查再继续
- 角色语言必须有辨识度——不能所有角色说话一个味
- 感官描写不能只有视觉——五感至少覆盖三种
- 对话不能只是推进剧情——要同时展现角色性格

---

### 5. 🔍 审校阶段（Refine）

**灵感来源**：上下文管理法 + AI漂移检测 + 文风统一法

**核心任务**：确保全书一致性、连贯性、文学质量

**子步骤**：
1. **一致性检查**：
   - 角色一致性：性格/语言风格/能力是否前后统一
   - 时间线一致性：时间/季节/年龄是否矛盾
   - 逻辑一致性：因果链是否成立，有无剧情漏洞
   - 世界观一致性：规则是否前后矛盾
2. **伏笔闭环检查**：
   - 所有预埋伏笔是否都已回收
   - 回收方式是否与埋设时暗示的一致
3. **文风统一润色**：
   - 全书语言风格是否统一
   - AI生成痕迹检测与消除
   - 对话节奏调整
   - 叙述节奏优化
4. **产出**：终稿 + 审校报告

## 8大独特优势

| # | 优势 | 来源融合 | 竞品有无 |
|---|------|---------|---------|
| 1 | 🎬 探矿式需求挖掘 | GSD苏格拉底提问 | ❌ 全没有 |
| 2 | 📊 创意成熟度量化 | GSD模糊度评分 | ❌ 全没有 |
| 3 | 🧩 灰区决策识别 | GSD灰区机制 | ❌ 全没有 |
