## 核心规则

### 穿越规则
1. **触发条件**：醉酒入梦（三瓶青岛啤酒），不可复制、不可控
2. **时间流速**：梦里过12年（2012-2024），现实过一夜
3. **记忆携带**：陈默带着2012-2024年全部记忆回到18岁身体
4. **身体状态**：18岁的身体（没有茧的手、近视不严重、体力充沛），但保留32岁的思维和情感

### 金手指规则（未来知识）
1. **力量**：知道GPU/AI行业的全部技术路线、关键节点、英伟达战略决策内幕
2. **衰减机制**：蝴蝶效应——他每改变一次历史，那条时间线上的"未来知识"就可能失效。改得越多，知道得越少
3. **记忆模糊**：只有脑子里的记忆，没有外挂数据库。越接近穿越时间点（2024），细节越模糊
4. **不可改变的历史锚点**：某些大事件无法改变（中美科技战、疫情、AI爆发），他能做的是在这些锚点之间找到缝隙
5. **到期日**：当蝴蝶效应累积到足够程度，金手指基本失效。此时他必须靠真正的能力

### 梦境规则
1. **梦的裂痕**：偶尔出现的"不真实感"——某些细节和记忆不一致（伏笔：暗示梦的本质）
2. **梦醒触发**：故事不主动揭示，但暗示与"为自己活"的领悟有关
3. **梦醒后**：物理世界不变（出租屋、裁员邮件），但枕头下的纸条暗示"梦不只是梦"

## 约束与禁忌

### 硬约束（不可突破）
1. **不能一个人造出GPU**：这是系统工程，需要数百人的团队、数亿资金、完整的产业链
2. **不能提前做出ChatGPT**：算力不够、数据不够、理论基础不够。但可以提前布局方向
3. **不能改变历史大事件**：中美科技战、疫情、AI爆发——这些锚点不变
4. **不能让所有人相信他**：没有"预言"能力，只有知识。说出来的未来没人信，只能用结果说话
5. **梦终究会醒**：梦里的12年再真实，也会在某个时刻结束

### 叙事禁忌（写作层面）
1. **不给金手指开挂**：每次用未来知识必须有代价（暴露风险/蝴蝶效应/信息差穿帮）
2. **不给主角开后宫**：四女主有独立人格和选择权，不是"收集"对象
3. **不给反派降智**：英伟达是真正的对手，不是纸老虎
4. **不靠运气推进情节**：每一个转折都有因果逻辑

## 崩塌代价规则

**金手指失效的崩塌路径**：
1. **先崩小预测**：某个小投资机会因为蝴蝶效应错过了
2. **再崩技术细节**：某个架构参数因为产业链改变而不再准确
3. **然后崩战略预判**：英伟达的某个决策因为市场变化而和他记忆中的不同
4. **最后崩核心信念**：他一直以为"重来一次就能做对"，但发现选择没有对错，只有代价

**情感线的崩塌路径**：
1. 先从"可控"开始——苏晚晴不是他想象的那么简单
2. 再到"不可控"——叶霜独立做出的判断超越了他的预判
3. 然后"被选择"——秦岚选择了信念而非他
4. 最后"被放手"——沈灵不需要任何人的拯救

## 声音锚定

**第一人称叙述风格**：
- 前期（V1-V2）：吐槽式自嘲，节奏快，短句多，内心独白密集。"三瓶青岛啤酒下去，我的人生选择了重启。"
- 中期（V3-V4）：渐沉稳，内心独白变少，更多观察和判断。幽默从自嘲变成冷幽默。
- 后期（V5-V6）：克制，留白多。偶尔闪现前期的自嘲，但带着释然。
