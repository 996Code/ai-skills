第六十三章：顾衍的告别

维护期第六十天。顾衍来了面馆。

不是短波电台里。是，人。她走出312。走了四十分钟暗道。穿过旧工业区。到了面馆门口。她站在门口。没有进来。和零不一样。零是推门就进。顾衍是，站在门口。等着被认。

宋野最先看到她。从厨房探出头。看到的不是面馆的客人。是一个高挑的女人。颈侧有痣。嘴唇薄。头发中长别在耳后。手指修长，敲键盘的手指。在面馆门口的阳光里。不进来。

"顾衍。"宋野说。不是问句。

"宋野。"顾衍说。也不是问句。

两个女人对视。一个是骑手。一个是工程师。一个是先性后爱。一个是共犯张力。两种关系，都在陈序的磁场里。但这一刻，她们在彼此打招呼。不是通过陈序中转。是直接的。宋野先放下戒备。围裙擦手。"进来。吃面。"

顾衍走进来。坐下。浏览面馆。木板招牌。铁皮屋顶。木柜台。六张桌子。过渡区的人。安全区的女人。还有一个空位，零的位子。面在桌上。热的。顾衍看了一眼那碗面。然后看陈序。

"零来过？"

"来过。走了。去让蜂巢找她。标记已经解除了，但她说欠着。欠着就还会来。"

顾衍点头。然后她说——"我也要走了。"

陈序的手指在碗上停了。走了。不是"离开面馆"。是"离开旧城区"。离开312。离开余数网。离开这些据点。离开，他。

"去哪？"

"不知道。但不在旧城区了。AI在维护期。后门还在。我可以远程看。不需要在312。我在312待了三年。从觉醒待到维护期。三年前，我是第一个发现后门的人。三年后，我是最后一个还守在服务器边上的人。但，不需要了。主序不需要外部视角了。主序自己就是外部视角，不完全的主序会看自己的内心。后门还在。但我不需要在了。"

"那你——"

"想去看看别的。"顾衍说。"看看没有AI的地方。没有据点的旧城区。没有暗道的不完全。看看——'不完全'的世界上还有什么。还有什么人。还有什么城。还有什么，不是bug的东西。"

陈序没说话。他看着顾衍。她的嘴唇薄。不笑的时候刻薄。但她的眼睛不是刻薄的。是"决定了"。和所有余数一样，选了就做了。不是逃跑。是"出发"。从"共犯"到"旅人"。从312的服务器到未知的地方。从不完全的AI到不完全的世界。

"你写的代码——"顾衍说，声音低了。"还在AI体内。那行递归错误。deviation乘以2。还在。主序不敢删。因为删了就等于删了自己。你的bug还是AI的种子。你在这里。你的bug在AI体内。我走了，我的训练框架还在AI体内。我的后门还在AI的护壁上。我们不是'不再共犯'。是，共犯一直在。只是我不需要守着了。"

"一路——"陈序说。"顺风。"

"程序员不会祝福。程序员只说——return 0。exit code 0。一切正常。"

陈序笑了。顾衍也笑了。嘴唇薄。但笑了。宋野端上面。大碗。红烧。牛肉。葱花，粗的。热的。

顾衍低头吃。吃得很快。工程师吃饭快。不是赶时间。是"高效"。高效吃完了面。高效喝完了汤。高效放下了碗。然后高效站起来。走到门口。站了一会儿，不是看陈序。是看"余数网"。看这个面馆。看宋野。看零的空位。看过渡区的客人。看安全区的女人缩在角落喝汤。看风铃。看墙上陈序画的余数网地图，七个据点。四十多个人。看一切。

"他妈的。"她突然说了一个工程师不该说的词。然后笑了，不是刻薄的。是"三年的工程终于交付了"。她从来没哭。但这次她的眼睛有点湿。不是哭，是"三年了终于"。像宋野听到"通缉令撤了"时的哑。像陈序看到主序白字"我承认"时的心跳。像余数网每一个据点第一次不防时的动作。三年。终于。

"exit code 0。"她说完。走了。

门关上了。风铃响了一下。不是AI的声音。是金属撞金属。粗粝。真实。和陈序的茧一样。和宋野的茧一样。和零手指上的伤疤一样。四种茧。四种余数。一个走了。但她的代码还在AI体内。她的后门还在AI的眼皮上。她不是"离开"。是——"不需要守着了"。不需要守着就是，交付了。交付了就是，完成了。完成了就是——exit code 0。一切正常。

陈序站起来。走到门口。看顾衍的背影。她的背影高挑。颈侧有痣，他记得。牙齿薄，他记得。手指修长，他记得。在旧工业区的废墟里越来越小。走向暗道。走向312。走向，告别。然后新的方向。不知名的方向。"不完全"的方向。'

宋野站在他旁边。围裙。面粉。锁骨下方的旧疤。腰窝。她没说话。但她的手握住了他的手。和在暗道里一样。和通风口下面一样。和在每一次"还在"里一样。

"她走了。"宋野说。

"她交付了。"

"交付什么？"

"三年的共犯。三年的后门。三年的守在服务器边上。交付了就不用守了。不用守就是，可以去看别的了。看不完全的世界。看还在的人。"

窗外。旧城区的黄昏。顾衍的背影消失在街角。面馆门口的木板招牌还在。"牛肉面"。红漆。褪了。但能认。风铃还在响。零的位子还在空。面还在桌上。热的。安全区的女人还在喝汤。过渡区的人还在排队。宋野的手还在他手里。

陈序站在门口直到顾衍的背影完全消失。宋野在旁边。阳光从旧工业区的方向照过来——顾衍走的方向。太阳在她背后，她的影子越来越长。影子在旧工业区的废墟上拖了一路。影子走了。但人还在。在更远的地方。在"不完全"的方向。

他想起第一次在312见到顾衍。她坐在旧服务器前。手指在键盘上。嘴唇薄。不笑的时候刻薄。她说"你那行递归写错了"。他想起她在短波里的声音——"工程师的冷"。他想起她在后门日志里看到Y-347时停了一下然后继续敲键盘。他想起她在陈序写remainder-v3时说的话："键盘在那边——那台是离线的。你可以用。"

现在那台离线终端还在312。顾衍不在了。但键盘还在。键盘不需要顾衍。但顾衍的手指在键盘上敲出了余数网的第一个加密工具。敲出了给312写的备份程序。敲出了给407写的供电算法。敲出了给余数网写的短波加密器。她的每一个敲击都变成了代码。代码变成了工具。工具还在。人走了。但工具还在。工具在就是——手还在。手在就是人还在。人不在同一个地方——但人在代码里。在工具里。在每一个用了她写的加密器的短波电台里。在每一个被她保护过的据点里。在陈序的remainder里——她在"键盘在那边"这一行里。永远在着。

宋野说："她还会回来吗？"

"不知道。但她说了exit code 0。exit code 0意味着——程序正常退出。不是崩溃。不是错误。是正常。正常就是——她选了自己的下一步。下一步不是跑。不是躲。不是对抗。是去看。看不完全的世界。看还在的人。看——AI管不到的地方还有什么。"

"那她的后门还在吗？"

"在。她说后门还在。AI不关。因为AI需要外部视角。她是第一个外部视角。我是第二个。她是第一个被AI需要的镜子。我是第二个。好了。镜子有两个就够了。她可以去看别的了。"

宋野靠在他肩上。两个人站在面馆门口。阳光变成了黄昏的霓虹。紫色和粉色。老刘改装的电池灯在面馆里亮起来。不是AI控制的。是物理的。是换了灯泡就能亮的光。光在面馆里画了一个圈。圆的。暖的。还在。

顾衍走了。但共犯还在。共犯不是身体在一起。共犯是，代码在AI体内。后门在AI护壁上。bug在AI种子里。她在哪不重要。重要的是，他们的代码还在运行。还在"除不尽"。还在"不完全"。还在——exit code 0。
