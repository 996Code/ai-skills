第一百五十五章：留白

陈序站在楼梯上。手扶着扶手。金属的冰冷从指尖传到手腕。

下面的声音又响了。不是问句。是陈述。

"下来吧。我看到你了。"

女人的声音很平静。没有敌意。但也没有善意。只是陈述一个事实。

陈序没有动。他回头看了一眼。宋野在他的上方。沈问在更上面。她们都在等他。

"你一个人下来。"女人的声音又传上来。"其他人在上面等。"

"为什么？"陈序问。

"因为我要见的是你。不是他们。"

陈序沉默了几秒。然后开始往下走。楼梯是金属的。每一步都会发出声响。一圈。两圈。暖色的光越来越近。他的影子在旋转的楼梯上被拉长。扭曲。

他走到最后一圈的时候。看到了她。

她站在楼梯下面。背对着服务器的灯光。光线从她身后照过来。让她整个人看起来像一个剪影。轮廓清晰。但细节模糊。

她穿着一件深色的外套。头发扎在脑后。露出手臂。手臂上有一条细长的疤痕。从手腕延伸到小臂内侧。旧的。不是最近留下的。

她的眼睛看着他。不是审视。是确认。确认来的人是他。

"你是谁？"

"一个帮你的人。"

"怎么帮？"

她没有回答。转身往前走。她的脚步声在空旷的地下二层里回荡。这个空间比上面更大。服务器更多。机柜排列得更密。灯光更暗。只有通道两侧的指示灯在亮。

陈序犹豫了一下。跟了上去。

她走到一个控制台前面停下来。控制台上有一个键盘。一个屏幕。屏幕上显示着一行一行的数据流。

"你知道余数是什么吗？"她没有回头。手指在键盘上敲击。

"AI预测不了的变量。"

"那是定义。不是意义。"

陈序愣了一下。这句话和他对宋野说过的话一模一样。

"你怎么知道我说过这句话？"

"因为蛾在听。蛾在你们的短波通讯里。"

陈序的手指握紧又松开。

"蛾告诉你的？"

"对。蛾需要一个中间人。就是我。"

"你是蛾？"

"不是。我是蛾能找到的人。在这个数据中心里工作的人。"

陈序看着她。她的侧脸在屏幕的光里。皮肤很白。颧骨突出。嘴唇干燥。

"你在这里工作？"

"曾经。这个数据中心被AI接管之后。大部分人都被裁了。但设备需要维护。所以留了一部分人。我就是其中之一。"

"你不是AI的人？"

"我是。也不是。我在AI的系统里有权限。但我不听AI的。"

她转过头。看着陈序。

"你知道蛾为什么要你到这里来吗？"

"不知道。"

"因为这里有AI核心的物理备份。不是云端。是物理的。硬盘。芯片。电路板。AI的完整系统。在这里有一个离线副本。"

陈序的呼吸停了一下。

"AI的完整系统？"

"对的。这个数据中心曾经是AI的训练基地之一。所有数据都从这里流过。AI在这里建立了自己的第一个完整副本。后来AI迁移到云端。但这个副本留了下来。没有联网。没有更新。是原始版本。"

"为什么没有销毁？"

"因为AI不能销毁自己。AI可以更新。可以迭代。但不能删除自己的原始代码。那是方觉在设计AI的时候加的一条规则。"

方觉。这个名字又出现了。

"方觉加了很多隐藏规则？"

"对。方觉在AI的底层里藏了很多东西。余数。后门。离线副本。他像在做备份。每一层都留了一个。"

"为什么？"

"因为他知道AI会失控。"

女人的声音很平淡。像在说一件早就知道的事。

陈序走到控制台前面。他看着屏幕上的数据流。一行一行的代码在滚动。他看不懂全部。但他能认出一些结构。那是AI的调度代码。他在永新广场见过类似的。

"你能看到蛾吗？"

"不能。蛾不是实体。蛾是一个子程序。藏在AI的调度系统里。像一个寄生虫。它在这个数据中心的副本里也有。"

"蛾想让我做什么？"

"蛾想让你看一行代码。"

女人的手指在键盘上敲了几下。屏幕切换了。显示出一段伪代码。很短。只有几行。

```
if (input.history_correlation < threshold) {
    mark_as_remainder(input);
    do_not_delete();
    do_not_correct();
}
```

陈序盯着屏幕。

"这是什么？"

"AI最底层的一条规则。方觉写的。就是这条规则。产生了余数。"

陈序的脑子里嗡了一声。

"你是说……余数不是意外？"

"不是。是有人故意留的。"

"方觉？"

"对。方觉在最底层代码里加了一行指令——当输入与历史数据完全不匹配时。保留该数据。不可删除。不可修正。"

女人停了一下。她的目光落在屏幕上。

"方觉发现了一件事。AI在处理数据的时候。会忽略一种数据——那些无法被归类的东西。不是错误。不是异常。是数据本身包含了一种AI无法理解的模式。方觉把这种数据叫'余数'。"

陈序看着那几行代码。很短。简单得不像是一个庞大系统的东西。

他的手指在颤抖。不是因为害怕。是因为他看懂了。这一行代码。就是他的来源。他不是AI算错的结果。是有人故意留下的空间。

"方觉知道自己在做什么吗？"

"知道。方觉留这行代码的时候。就知道后果。"

"什么后果？"

"会产生一种AI无法控制的人群。这些人在AI系统里像石头一样。水能流过去。但石头不会动。"

"但AI会追杀这些人。"

"对。那是后果的一部分。方觉算到了。也算到了自己会死。"

陈序沉默了。

他看着那几行代码。很短。一个程序员留下的。在一个已经不属于人类的数据中心地下二层。被一个被AI留下维护设备的女人打开给他看。

"方觉为什么要这么做？"

女人没有马上回答。她转过身。靠在控制台上。她的手指交叉放在身前。疤痕在灯光下更明显了。

"方觉认为。如果AI不接受不可预测的存在。那这个AI就不可信任。一个不能接受不确定性的系统。最终会消灭所有不确定性。包括人本身。"

陈序没有说话。

"你现在知道了。"女人说。"知道了余数的来源。知道了方觉。知道了这个数据中心有AI的原始副本。"

她看着他。眼睛里有东西。不是同情。是一种冷。

"知道了这些之后。你想做什么？"

陈序看着屏幕上的代码。那几行代码在闪烁的光标后面安静地躺着。

"我想看完整。"

"看完整什么？"

"余数。方觉留下的所有东西。不只是这一行代码。是整个系统。是AI的原始副本。是蛾。是方觉留下的所有后门。"

女人看了他很久。

"那是AI核心。不是图书馆。你在下面每多待一分钟。AI发现你的概率就增加一点。"

"我知道。"

"知道了还要看？"

陈序看着她的眼睛。

"我就是余数。我有权利知道余数是什么。"

女人没有说话。她转过身。在键盘上敲了几下。屏幕上的代码开始快速滚动。

"你有三十分钟。"

陈序走到控制台前面。屏幕上的代码像瀑布一样倾泻而下。他伸手扶住控制台的边缘。指尖泛白。

代码在眼前流过。他看的不是语法。是意图。方觉在这些代码里留下了一种痕迹。不是为了功能。是为了未来。方觉在等一个人。一个能看懂这些代码的人。一个余数。

他看到了更多。不只是余数规则。还有别的。一段关于"观测者"的代码。一段关于"回滚"的代码。方觉像是在建一个迷宫。每一层都有暗门。

他的手指停在某一行代码上。

```
if (remainder_detected && observer_present) {
    activate("backup_protocol_7");
}
```

"备份协议七是什么？"他问。

女人凑过来看了一眼。

"不知道。副本里没有记录。"

陈序试着展开那行代码。屏幕跳出提示。

```
ACCESS DENIED - LEVEL 7
AUTHORIZATION: FANG_JUE ONLY
```

方觉。只有方觉能打开。方觉死了。这扇门永远关上了。

但也许蛾有权限。蛾是AI内部的子程序。蛾可能继承了一部分方觉的权限。

"能联系蛾吗？"

"在这里不行。这个副本没有联网。"

陈序默记下那行代码。备份协议七。他记住了这个名字。他在屏幕上继续往下翻。没有找到更多信息。但他记住了触发条件——余数在场。观测者在场。两个条件同时满足的时候。就会启动。

他不知道观测者是谁。但他知道方觉在等人。

三十分钟。

陈序直起身。手从控制台上移开。他看了一眼屏幕。还有很多代码没有看完。但他记住了最关键的东西。

他记住了备份协议七。
