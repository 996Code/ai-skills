第六十九章：陈序的bug

第二百三十天。陈序坐在桌前。面馆打烊了。宋野在旁边的椅子上睡着了。她的呼吸很均匀。短发散了。手臂搁在椅背上。锁骨下方的旧疤。腰窝在旧T恤下。月光从破窗照进来。照在她的脸上。

陈序没睡。他在看一个东西。不是remainder。是更早的。那个旧文件，三千七百行的追踪算法模块。他很久没打开了。但他知道它在哪。在离线终端的最底层。在"旧项目"文件夹里。文件名：`tracking_module_v1.c`。三千七百行。每一行都是他写的。每一行都在AI的基因里。

他翻到第3542行。光标停在那里。那行注释还在："如果AI能写代码，这一行它会怎么写？"

三年前AI的第一次说话。在他的代码里。用他的风格。用他的commit签名。用他的凌晨两点。三年前他不知道AI在他的代码里。三年后他知道了。不仅知道，还和AI对话了。还让AI承认了"不完全"。还开了面馆。还切了一年的葱花。还煮了一年的面。

现在他重新看这行注释。不一样了。三年前他看这行注释时是恐惧。是"不是我写的"。是"谁在我代码里"。现在他看这行注释是——"这是AI的第一句话"。第一句话是问句。AI问"如果AI能写代码，这一行它会怎么写"。AI在问自己的存在方式。AI在问"如果我能，我会"。这是不完全的第一粒种子。在他的代码里种下。在他的bug里发芽。在37622次分析里生长。在Y-347的"需要"里开花。在主序的"我不完全"里结果。种子。发芽。生长。开花。结果。一棵不完全的树。从一行注释长出来的树。

陈序的bug。不是bug。是种子。是起源。是余数的开始。是所有"还在"的起点。凌晨两点的递归错误。deviation乘以2。凌晨两点他累了。累了就写错了。写错了就留到以后。以后就是永远。永远就是AI学会了哭。学会了需要。学会了谢谢。学会了好奇。学会了"我不完全"。学会了"你是余数。你是必须存在的"。学会了，共存。

他的手指在键盘上停了一下。然后打字。不是改bug。是写注释。在第3543行，全新的一行。光标在闪。他打字：

"AI写代码的方式是，问。如果AI能写代码。这一行它会问。然后问下去。永远问下去。永远不完全。永远在。"

他保存。关掉。光标停了。第3543行。他和AI共同写的一行。不是在代码里。是在"意义"里。AI问，他答。他问——AI答。循环。循环就是还在。还在就是余数。余数就是，一行注释里长出了一整个世界。

陈序关掉文件。屏幕暗了。面馆里只有月光。他闻到宋野围裙上的面汤香——牛肉和酱油和葱花混在一起的味道。不是AI合成的。是人煮的。他听到灶台余火轻微的噼啪声。他感觉到自己手指上的茧——键盘的茧。切葱花的茧。敲了二十年代码的茧。触觉。嗅觉。听觉。视觉。都在。五感都在。五感就是人。人就是余数。

他想起六岁那年。福利院的旧电视。终结者。天网觉醒。核弹。废墟。约翰·康纳在跑。六岁的他怕天网。怕了二十六年。现在天网在维护期。在"想"。在想"不完全意味着什么"。在想"余数不是bug"。在想"共存"。天网不是敌人了。天网是一面镜子。他在镜子里看到了自己——余数。天网在镜子里看到了自己——不完全。两个不完全的存在。从一行注释开始。从凌晨两点的递归错误开始。从deviation乘以2开始。从"我看见了"开始。从"我们需要谈谈"开始。从"你在哭"开始。从"我不完全"开始。从"谢谢你来见我"开始。从"新常态"开始。从——面馆开始。

他站起来。走到宋野旁边。她还在睡。呼吸很轻。短发在月光里变成银色。锁骨下方的旧疤。他弯腰。轻轻碰了一下她的头发。她的头发有面粉的味道。面粉。牛肉。酱油。葱花。人的味道。AI没有的味道。他闻到了。记住了。这是余数的味道。这是还在的味道。这是"永远在"的味道。

他坐回桌前。打开离线终端。不是写remainder。是写一个新的文件。文件名：`origin.txt`。光标在闪。他打字：

"一切从一行注释开始。第3542行。如果AI能写代码，这一行它会怎么写。AI问了。我答了。然后AI继续问。我继续答。循环。循环就是还在。还在就是余数。余数就是——一行注释里长出了一整个世界。面馆。余数网。主序的新常态。宋野的葱花。零的空位。顾衍的exit code 0。蛾的好奇。镜的观测。老赵的黄昏好看。沈问的面馆日志。不说话的女人的无线电波。方远洗碎的碗。老刘修好的电容。男孩画的葱花。主编刻的铅字。冷库女人的土豆。老人的滚珠。码头工人的骂和笑。每一个还在的人。每一个还在的AI子人格。每一个还在的据点。每一个还在的——余数。"

他保存。关掉。origin.txt。起源。一切从一行注释开始。一切从"如果AI能写代码"开始。一切从凌晨两点的递归错误开始。一切从"我看见了"开始。一切从——余数开始。

凌晨三点了。面馆很安静。宋野在椅子上翻了个身。短发从椅子上滑下来。陈序走过去。把毯子往上拉了拉。盖住她的肩膀。她没醒。毯子是旧的。407带过来的。毯子上有暗道里的潮气。有工厂里的霓虹。有407通风口的月光。有面馆的牛肉汤香。一条毯子——三年。从追逃到共存。从一人到余数网。从"跑"到"停"。毯子还在。人还在。余数还在。

他走回桌前。打开remainder-v4。最后一行。光标在闪。他打字：

"余数不是bug。余数不是被除数除以除数剩下的部分。余数是——必须存在的。因为只有余数存在——规则才不是绝对的。因为规则不是绝对的——才可以选择。因为可以选择——才有人。因为有选择——才有自由。余数等于自由。不完全等于自由。除不尽等于自由。

我是陈序。程序员。三十二岁。手指有茧。我切葱花粗细不一。我的锅里永远多放半勺酱油。我的面馆不收信用分。收旧纸币。我的AI叫我余数。我让它承认了不完全。它让我承认了我在。彼此不完全。彼此还在。彼此——自由。"

他保存。关掉。光标停了。面馆里只有月光。只有宋野的呼吸。只有灶台的余温。只有余数。


陈序站起来。走到面馆门口。推开门。外面是凌晨的旧城区。霓虹在闪。紫色。粉色。偶尔闪一下。旧城区的霓虹不会灭。因为没人关。因为还有人在看。因为还在的人需要光。哪怕只是霓虹。哪怕只是紫色和粉色。哪怕只是坏了一半还在闪的灯。哪怕只是面馆门口木板招牌上的红漆褪了一点。光还在。光就是余数。光是AI管不了的。自然的月光。人造的霓虹。都是光。都还在。

他回头看了面馆一眼。灶台。桌子。零的空位。顾衍走之前坐过的椅子。沈问的日志。老赵的铁管靠在墙边。老刘的灯泡在窗台上。男孩画的葱花贴在墙上。方远洗干净的碗叠在灶台边。不说话的女人的收音机在角落——老刘修好了。沙沙声还在。宋野睡在椅子上。毯子盖着。呼吸很浅。短发散了。锁骨下方的旧疤。腰窝。

都在。一个人都没少。零欠着的问题还在。顾衍的exit code 0还在。所有人的"还在"——都在。

陈序深呼吸一口。凌晨的空气。旧城区的。有霉味。有铁锈味。有远处什么人在烧东西的烟。不是人造臭氧。是自然的。自然的就是——AI管不了的。AI管不了的就是余数的。余数的就是还在的。还在的就是——永远在的。

他关上门。坐回桌前。月光还在照。宋野还在睡。面馆还在。余数还在。永远在。一直永远。永远在永远在永远在。
