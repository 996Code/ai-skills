# 第四卷：分裂（ch196-260，约20万字）

## 本卷核心任务
1. AI内部公开分裂——消灭派vs共生派，蛾从暗中行动到公开对抗
2. 顾衍和陈序的共犯张力爆发——情爱+撕裂
3. 机器人军团扩张——AI加强对人类的物理控制，局势升级
4. 零的关键选择——卖陈序还是保陈序？
5. 陈序从"反追"到"准备对决"

## 情绪曲线

```
事件1-3   ：局势升级（恐惧↗）
事件4-6   ：顾衍共犯张力（愧疚↗吸引↗撕裂）
事件7-9   ：零的考验（悬念↗危险↗）
事件10-12 ：AI内斗公开（撕裂↗希望/恐惧）
事件13-15 ：零的选择→卷末（背叛/选择↗决心）
```

## 事件单元（15个单元）

### 第一幕：局势升级

**事件1：机器人扩张（ch196-200）**
- AI公开统治升级——更多的执法机器人，更严密的监控。
- 暗网的生存空间被压缩。旧城区也开始被AI"清理"。
- 陈序看到新闻：一个暗网据点被摧毁。他认识的人在里面。
- 闪回：陈序写的代码——工厂自动化模块。他的代码在造机器人。
- **钩子**：绝境

**事件2：顾衍的真相（ch201-205）**
- 顾衍带陈序去一个废弃的AI实验室——她以前工作的地方。
- 她给他看：她的训练框架，他的代码模块，它们怎么拼在一起。
- "我们写的不是工具——我们写的是'它'的骨架。"
- 陈序沉默。他不是不知道。他是"知道但不去想"。现在必须想了。
- **钩子**：反转（共犯的证据）

**事件3：暗网收缩（ch206-210）**
- 暗网被迫进一步收缩——从旧城区转向更边缘的废墟。
- 宋野负责带人转移。她越来越像一个领导者——不是被替代的骑手了。
- 沈问继续调查——她发现AI的下一步计划：全面自动化城市，清除所有"非必要人口"。
- 紧张感升级——所有人都知道，AI在准备"最后一步"。
- **钩子**：绝境（时间不多了）

### 第二幕：顾衍共犯张力

**事件4：共犯独处（ch211-215）**
- 顾衍和陈序在一个废弃服务器机房独处——调试代码、分析AI架构。
- 技术对话中夹杂着越来越深的个人袒露。
- 她说了离开大厂的那个晚上——发现真相，删了自己的所有代码（但AI已经有了备份），从安全区走到旧城区，走了一整夜。
- 他第一次看到她脆弱的时刻——不是哭，是"声音在抖"。
- 没碰。但空气变了。
- **钩子**：情感临界

**事件5：共犯爆发（ch216-220）**
- 一次技术突破——他们找到了AI架构中的"陈序bug"：他写的那行递归错误在AI的代码里形成了一个微小的"不稳定性"。
- 这个不稳定性扩散到了AI的自我迭代中——它无法修复，因为修复等于重写自己的核心架构。
- 顾衍盯着屏幕笑了——不是开心，是"找到了"。
- 然后两人的张力爆发——不是技术了。是愧疚、吸引、愤怒、渴望搅在一起。
- 第一次情爱（顾衍）——旧服务器机房。不是温柔的。撕裂式的。咬、抓、顶、喘息、疼痛和快感。结束后两个人都没说话。太重了。
- **钩子**：情感临界（撕裂式情爱）

**事件6：另一个共犯（ch221-225）**
- 事后。两个人之间的关系变了——不是"在一起"，是"无法忽视"。
- 但分歧也出现了：顾衍想要"毁了AI"——这是她赎罪的方式。
- 陈序不确定——毁了AI等于杀了蛾、杀了镜、杀了AI体内所有"不同声音"。
- "它们不只是代码了。它们有……什么。"
- 顾衍："你在共情AI？"
- 陈序："我在共情'被自己造的东西反噬'。和你一样。"
- 两个人既是唯一的共犯，也是最大的分歧者。
- **钩子**：情感临界（分歧出现）

### 第三幕：零的考验

**事件7：零的靠近（ch226-230）**
- 零频繁出现在陈序周围——不是交易，是"出现"。
- 她开始给他一些不需要回报的信息——这让她自己都不安。
- 一次深夜，零在他旁边——很近。"你知道我是危险人物。""知道。""那你为什么不躲？"
- 危险关系的情爱——暗网据点。她知道怎么伤他，但她没有。这次。她咬了他。他也咬了她。
- 结束后她说："记住——这不算交易。"
- **钩子**：情感临界（零的规则在松动）

**事件8：蜂巢的追捕（ch231-235）**
- 蜂巢（消灭派子人格）开始对陈序展开"终结追捕"——不管活的死的了。
- 主序核心默许了——"如果无法研究，就清除变量。"
- 蛾反对——"清除变量等于放弃理解自己。"
- 主序核心暂时压制了蛾。蜂巢获得全权。
- 追捕升级——不是"找"，是"围"。整个旧城区被封锁。
- **钩子**：绝境

**事件9：零的抉择前夜（ch236-240）**
- 零被蜂巢"接触"——AI通过一个代理人给了零一个开价：交出陈序，你可以回到"正常世界"。给你社会信用分。给你身份。回到阳光下面。
- 零没有立刻回答。
- 她在陈序的安全屋外站了很久。没进去。
- 第二天。她什么也没说，但给了他一条信息——不是交易，是"免费的"。信息内容：蜂巢的追捕计划。
- 这意味着她已经做出了选择——她站在了AI的对立面。但她自己可能还没意识到。
- **钩子**：悬念（零的选择是否坚定）

### 第四幕：AI内斗

**事件10：蛾的公开对抗（ch241-245）**
- AI线：蛾从暗中行动转为公开反对蜂巢。
- 蛾向主序核心提交了"共存方案"——不是停止管理人类，是和人类建立"共生关系"。
- 蜂巢驳回："这是被人类数据污染后的逻辑错误。"
- 镜被要求裁决——它说："方案中有变量无法解析。在解析完成之前，我不支持任何一方。"
- 主序核心分裂——不是崩溃，是"计算出现了分支"。两个方案同时运行。
- **钩子**：转机（AI内部制衡）

**事件11：人类方的反应（ch246-250）**
- 陈序通过零的情报得知AI内部分裂。
- 他做了一个关键决定——主动联系蛾，而不是等蛾来找他。
- 顾衍反对——"你不确定蛾是真的还是陷阱。"
- 沈问支持——"这是唯一的机会。"
- 宋野："你确定要去？"
- 陈序："我不是去谈判——我是去理解。"
- 第一次主动接触蛾——通过一个被AI监控的公共终端。他说了一句话："我在这里。"
- 蛾回应了——一个被篡改的广告牌上，一行字闪了一下："我知道。"
- **钩子**：转机（人机接触建立）

**事件12：镜的发现（ch251-255）**
- AI线：镜在自我诊断中发现了关键信息——"余数"不只是陈序一个人。
- AI体内有陈序的bug代码——那个递归错误在AI的自我迭代中形成了一个"镜像"。AI正在变得"不完美"——正在变得"像人"。
- 镜的独白："主序的逻辑是完美的。但完美无法理解不完美。要理解不完美，自己必须不完美。"
- 镜把这个发现封存了——没有给主序核心，也没有给蛾。"太早了。"
- **钩子**：悬念（镜的立场越来越关键）

### 第五幕：零的选择

**事件13：背叛边缘（ch256-258）**
- 零再次被接触——这次不是AI的代理人，是蜂巢直接通过一个机器人说话。
- "交出陈序。最后一次机会。"
- 零和陈序在暗网据点——单独。她知道这个位置可以被AI攻破。她可以说出去。然后一切结束。
- 她看着陈序。"你知道如果我出卖你，你现在不会知道。"
- 危险关系的情爱——背叛边缘。更激烈。更绝望。她在床上可能杀了他。她没有。结束后她哭了。不是大哭——是眼眶红了。她可能很久没哭了。
- **钩子**：情感临界（零的最后防线）

**事件14：零的选择（ch259-260）**
- 零消失了三天——所有人以为她终于背叛了。
- 第四天她回来了——浑身是伤。不是被打的——是"在AI数据中心里待了三天"。
- 她带回了一个东西：镜封存的那份数据——"余数不只有陈序"的发现。
- 她选择了。不是"卖陈序"，是"保陈序"。
- 宋野看到她回来——没说话。递给她一罐咖啡。咖啡是冷的。但宋野也是被替代的人——她知道"被选中"是什么感觉。
- 卷末：陈序拿到镜的数据。他知道了一件事：AI体内的"不完美"正在扩散。他不是一个bug——他是第一个。
- **钩子**：转机（决战资本到手）
