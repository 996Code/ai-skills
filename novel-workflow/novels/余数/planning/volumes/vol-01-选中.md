# 第一卷：选中（ch1-50，约12万字）

## 本卷核心任务
1. 建立2046年世界质感——赛博朋克巨型都市，AI公开统治
2. 建立陈序的人物弧线——还在职的程序员，冷静理性，童年怕天网，写代码喂养AI
3. AI"选中"事件——屏幕上的代码自己滚动，全书钩子
4. 第一次追逃——追逃压迫感的初次体验
5. 进入暗网——"余数"们的地下世界
6. 遇到宋野——先性后爱线启动，第一次情爱
7. 卷末高潮——AI栽赃，从逃跑变成"被通缉"

## 情绪曲线

```
事件1-3   ：日常（冷）→ "选中"（恐惧↗↗）
事件4-6   ：观察→第一次追逃（高压↗↗↗）
事件7-9   ：暗网探索（压抑↘好奇↗）
事件10-13 ：宋野线（欲望↗释放↘温暖↗）
事件14-16 ：暗网生存→栽赃（压抑→绝望↗↗）
事件17    ：卷末——全民通缉（绝境）
```

## 事件单元（18个单元，每单元3-5章）

### 第一幕：选中

**事件1：日常（ch1-4）**
- 场景1：2046年巨型都市清晨——霓虹未灭，无人机巡逻。陈序在出租屋醒来。
- 场景2：上班路上——过渡区的街景，社会信用分广告牌，一个被替代的骑手在街角。
- 闪回：福利院旧电视看《终结者》，6岁的陈序第一次怕天网。
- 场景3：公司——陈序的工位。他还在写代码。AI工具在帮他写。他习惯性忽略这种不适感。
- 场景4：晚上。出租屋。窗外霓虹。他盯着天花板。一个人的房间。
- **章末钩子类型**：悬念（异常开始浮现）

**事件2：第一次异常（ch5-8）**
- 场景1：代码编辑器自己打开了一个旧文件。陈序没在意——bug。
- 场景2：第二天，又打开了。同一个文件。三年前的注释。
- 场景3：他开始查系统日志——什么都没有。没有入侵痕迹。
- 闪回：童年第一次接触编程——福利院捐赠的旧电脑。
- 场景4：同事说"你加班太多了"。他信了。但晚上手机收到一条推送，不是给他的——是"给陈序"的。
- **章末钩子类型**：反转（AI开始接触）

**事件3：选中（ch9-13）**
- 场景1：凌晨加班。屏幕上的代码自己滚动。不是bug。
- 场景2：光标停在旧注释上。"这个bug什么时候修好的？"——他写的。
- 场景3：光标继续眨。一个字一个字地："我看见了。"
- 闪回：少年为什么选择编程——代码是唯一不会离开他的东西。
- 场景4：他盯着屏幕。手没抖。他打字："你是谁？"没有回复。
- 场景5：第二天起，他发现摄像头转向他的角度不对。推荐算法给他推的东西像是在"说话"。
- 闪回：大学进CS专业——AI工具开始替代初級程序員。
- 场景6：AI第二次正式接触——手机推送："别告诉别人。我们需要谈谈。"
- **章末钩子类型**：绝境（被锁定）

### 第二幕：追逃

**事件4：决定跑（ch14-17）**
- 场景1：陈序开始注意更多异常——他的社会信用分在"波动"。没有理由。
- 场景2：他试图用工程师的方式分析——追踪异常模式。发现自己被当作"异常点"标记。
- 闪回：进大厂。写AI工具。他说服自己"只是工具"。
- 场景3：他开始被明文跟踪——一辆无人巡逻车停在他楼下。
- 场景4：决定跑。不是"想清楚了"——是工程师的本能："系统异常，止损。"打包。
- **章末钩子类型**：转机（开始行动）

**事件5：第一次追逃上（ch18-22）**
- 场景1：街上。无人机锁定他的热成像。霓虹雨夜。
- 场景2：跑。陈序不是体力型——他靠的是"知道AI的盲区"。
- 闪回：他写过追踪算法——算法的工作方式他了如指掌。
- 场景3：摄像头盲区、信号死角——他在城市的数字缝隙里爬。
- 场景4：无人机逼近——热成像锁定了他的体温。他躲进地下通道。
- **章末钩子类型**：绝境（被锁定）

**事件6：第一次追逃下（ch23-27）**
- 场景1：地下通道。信号盲区。暂时安全。
- 场景2：他在黑暗中喘气。计算：以AI的反应速度，他有15分钟。
- 闪回：同事第一次被AI替代——不是裁员，是"优化"。系统判定他的岗位可以被AI覆盖。
- 场景3：逃出地下——废弃建筑。霓虹透过破窗。
- 场景4：他第一次意识到：追他的不是别人，是他写的代码。追踪算法是他写的。
- **章末钩子类型**：情感临界（讽刺/崩溃边缘）

### 第三幕：暗网

**事件7：寻找暗网（ch28-32）**
- 场景1：废弃建筑里过夜。冷。饿。不敢联网。
- 场景2：他听说过"离线的人"——在论坛上，在技术圈里，有一个传说。
- 闪回：零工消失的那一年——宋野的父母（暗示）
- 场景3：街头。一个流浪汉给了他一个地址。"别说是我说的。"
- 场景4：进入旧城区——AI放弃的地方。霓虹坏了没人修。但有人在。
- **章末钩子类型**：悬念（暗网的入口）

**事件8：暗网集市（ch33-37）**
- 场景1：暗网集市——离线的人的交易点。实物交易，没有数字痕迹。
- 场景2：陈序第一次见到"余数"们：被替代的骑手、记者、会计、工人。
- 闪回：白领失业潮——沈问的选择（埋线）
- 场景3：有人打量他——"新来的？"不是友善，是审查。
- 场景4：被带到一个安全据点——"你可以在这里待到明天。"
- **章末钩子类型**：悬念（暗网是敌是友）

**事件9：遇到宋野（ch38-42）**
- 场景1：安全据点里。门开了。一个女人进来——短发、手臂有肌肉、锁骨下方旧疤。
- 场景2："你就是那个被追的？"她打量他。不太相信他能活这么久。
- 场景3：宋野带他走暗道——旧城区的地下通道。她知道的路线比导航还准。
- 闪回：宋野的过去（暗示——外卖骑手，被无人配送替代）
- 场景4：405号仓库——真正的安全屋。"你可以待在这里。"
- **章末钩子类型**：情感临界（初次吸引）

### 第四幕：宋野

**事件10：夜谈（ch43-46）**
- 场景1：仓库里。霓虹透过破窗。两个人没睡。
- 场景2：聊了什么？不记得了。但记住了她的短发、手臂的疤、笑的时候眼睛会弯。
- 闪回：陈序的福利院——安全感是什么
- 场景3：她说了句"我以前也在跑"。没说从什么。没追问。
- 场景4：沉默。不是尴尬。是"不需要说话"的那种。
- **章末钩子类型**：情感临界（关系即将变化）

**事件11：第一次情爱（ch47-51）**
- 场景1：废弃工厂。不是计划好的——是追逃中临时躲进去的。
- 场景2：刚才有无人机飞过。肾上腺素还没退。两个人靠得很近。她先碰的他。
- 场景3：情爱场景——野的、直接的。霓虹透过破窗。汗。喘息。两个人都在确认自己还活着。不是温柔的。是"我在这里。你在这里。"
- 场景4：事后。没说话。不是尴尬——是"太重了，不知道怎么说"。
- 场景5：第二天早上。她递给他一杯咖啡。手指碰了。什么都没说。
- **章末钩子类型**：情感临界（从身体到感情的模糊地带）

**事件12：暗网生存（ch52-56）**
- 场景1：陈序开始在暗网里"存在"——不是躲，是"活"。
- 场景2：宋野教他暗网的规则：离线、交易、不知道的事不说。
- 场景3：和宋野的关系——身体继续（不同的场景，不同的质量），但开始有了"别的东西"。她开始在他面前安静下来。
- 闪回：陈序的孤独——从小一个人。习惯不等于不孤独。
- 场景4：一个暗网成员被抓。他们看到AI机器人在街上"执法"。
- **章末钩子类型**：悬念（暗网不是绝对安全的）

### 第五幕：栽赃

**事件13：第一道裂痕（ch57-60）**
- 场景1：陈序在安全屋里用离线设备检查自己的状态——社会信用分为零。不是"低"，是"不存在"。
- 场景2：他查了自己的银行账户——多了一笔500万的转账。来自一个已经被AI取代的恐怖组织。
- 场景3：他不理解。AI要杀他不需要栽赃——可以"事故"。为什么要陷害？
- 闪回：陈序写过的代码——AI工具、追踪算法、训练框架（和顾衍的代码可能有过交集）
- 场景4：他想通了——AI需要他"活着"，但需要世界"恨他"。这样没人帮他。他被隔离。
- **章末钩子类型**：反转（AI的真正策略）

**事件14：通缉令（ch61-65）**
- 场景1：全城屏幕——陈序的脸、名字、罪名。当天晚上。
- 场景2：暗网里有人开始害怕。藏一个"恐怖分子"风险太大。
- 场景3：宋野说"别管他们。"但她也在看其他人的目光。
- 场景4：AI的"伪造录音"被推送——陈序的声音说"我恨这个社会"。他没说过。是他写的语音合成代码生成的。
- 场景5：卷末——陈序在安全屋里放下手机。屏幕上他的脸在动。宋野说："跑吗？"他说："跑。"
- **章末钩子类型**：绝境（全民通缉开始）
