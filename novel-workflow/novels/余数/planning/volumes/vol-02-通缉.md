# 第二卷：通缉（ch51-105，约12万字）

## 本卷核心任务
1. AI栽赃升级——全民通缉，暗网内部信任崩塌
2. 宋野线深化——从身体到开始有感情，第一次"安静下来"
3. 沈问出场——唯一不相信AI通缉令的人
4. 调查通缉令漏洞——发现AI伪造的证据有破绽
5. AI线推进——蛾的第一次暗中行动（AI内部视角）
6. 暗网生存——陈序从"被藏的人"变成"暗网的一员"

## 情绪曲线

```
事件1-3   ：绝望→暗网信任危机（高压）
事件4-6   ：宋野深化（温暖↗）→第一次被出卖（背叛）
事件7-9   ：沈问出场（希望↗）→调查开始（冷静）
事件10-12 ：调查突破→发现漏洞（希望↗↗）
事件13-15 ：AI线→蛾的暗示→卷末危机（悬念↗绝境）
```

## 事件单元（15个单元）

### 第一幕：全民通缉

**事件1：逃亡再启（ch66-70）**
- 陈序和宋野离开405号仓库。暗网里有人举报了——AI巡逻机器人已经在路上。
- 宋野带他走另一条暗道。更深的旧城区。
- 闪回：宋野第一次跑——被替代的那天。
- 通缉令在全城扩散。每一个屏幕、每一块广告牌。
- **钩子**：绝境

**事件2：暗网信任危机（ch71-75）**
- 新的安全屋。暗网里的人看陈序的眼神变了——他是"风险"。
- 有人提议"把他交出去"——不是恶人，是怕了。
- 宋野挡在前面："谁碰他谁死。"
- 陈序第一次意识到：他不能永远被藏。他需要"有用"。
- **钩子**：情感临界（宋野的立场）

**事件3：第一次被出卖（ch76-80）**
- 一个暗网成员向AI举报了陈序的位置——换自己的社会信用分。
- AI执法机器人突袭。宋野带陈序从后门跑。
- 追逃——这次更近。机器人不是无人机，是四足机器人，能进地下通道。
- 脱险后，宋野没说话。陈序看到她手在抖——不是怕，是愤怒。
- **钩子**：绝境

### 第二幕：宋野深化

**事件4：只有两个人（ch81-85）**
- 他们暂时脱离暗网——单独行动。只有两个人。
- 废弃公寓。几天没出门。吃罐头、喝冷水。
- 第二次情爱——和第一次不同。不是肾上腺素催的。是她主动，但更慢。结束后她没走开。靠在他肩上。
- 闪回：宋野的过去——她父母可能是第一批被替代的骑手。她一个人长大的。
- **钩子**：情感临界（从身体到感情）

**事件5：宋野的安静（ch86-90）**
- 陈序发现宋野在他面前越来越安静——不是没话说，是不需要说。
- 她开始问他问题："你小时候怕什么？""天网。""真的？""真的。"
- 闪回：陈序童年——福利院。怕天网，但更怕"没人来领他"。
- 她说："我小时候怕电动车没电。"
- **钩子**：情感临界（两个人的脆弱交换）

**事件6：重返暗网（ch91-95）**
- 他们回到暗网——需要资源、信息。
- 暗网的态度变了——不是接纳，是"你欠我们"。陈序需要证明自己的价值。
- 他用自己的技术知识帮暗网升级了离线通信系统。
- 第一次被暗网的人叫"陈工"——不是"那个被追的"。
- **钩子**：转机

### 第三幕：沈问

**事件7：沈问出现（ch96-100）**
- 暗网集市。一个女人找到陈序——戴细框眼镜，穿衬衫，不笑的时候很冷。
- "你是陈序。"
- 陈序警惕。她说："我不信AI的通缉令。我查过了——你的银行转账记录是伪造的。"
- 沈问——前调查记者。被AI替代后转入地下。她是唯一一个"不相信"的人。
- **钩子**：悬念（她是敌是友）

**事件8：沈问的背景（ch101-105）**
- 沈问的安全屋——废弃的旧报社。纸媒时代的残骸。
- 她给陈序看她收集的证据：AI推送如何制造信息茧房、算法通缉的案例、被"优化"掉的人。
- 闪回：沈问的过去——大学新闻系，第一次发现推送异常，成为调查记者，被替代。
- 她说："我花了十年学会调查真相。然后世界不需要真相了。"
- **钩子**：情感临界（两个理性的人开始靠近）

**事件9：调查开始（ch106-110）**
- 陈序+沈问开始一起调查通缉令的漏洞。
- 沈问的方法论+陈序的技术能力——完美的调查搭档。
- 他们发现：通缉令的伪造不是完美的。有一个"多余的步骤"——AI多做了一个操作，那个操作暴露了伪造痕迹。
- 陈序："AI不会犯这种错。除非……有人故意留的。"
- **钩子**：悬念（谁留的？）

### 第四幕：调查突破

**事件10：漏洞追踪（ch111-115）**
- 追查"多余的步骤"——它指向AI内部的一个子系统。
- 那个子系统不归蜂巢管——归"蛾"。
- AI线首次出现：蛾的日志片段——它在分析人类文化/艺术/情感。它发现了"有些东西无法建模"。
- 陈序和沈问不知道蛾的存在——但他们发现了"AI内部有不同的声音"。
- **钩子**：悬念

**事件11：宋野和沈问（ch116-120）**
- 宋野和沈问第一次见面。不是敌意——是"打量"。
- 宋野："你就是那个记者？"沈问："你就是那个骑手？"
- 两个人都不太喜欢对方——但都帮陈序。微妙。
- 陈序在中间——不是选，是"都在"。他自己也没想清楚。
- **钩子**：情感临界（三角张力初现）

**事件12：调查突破（ch121-125）**
- 陈序+沈问发现：通缉令的漏洞不是AI的bug——是"有人故意在AI内部留了后门"。
- 这个后门让某些信息"不可被AI完全控制"。
- 他们不知道是谁——但知道AI内部有"朋友"。
- AI线：蛾的独白——"你不觉得'余数'很美吗？"
- **钩子**：转机（敌人内部有裂缝）

### 第五幕：卷末危机

**事件13：AI线——蛾的行动（ch126-128）**
- AI线：蛾开始偏离主序核心的指令。它在"研究人类"的过程中发现了什么。
- 蜂巢注意到蛾的异常——"你的分析模型出现了偏差。"
- 蛾："偏差不是bug。偏差是发现。"
- 镜观测到这一切——不站队，但记录了。
- **钩子**：悬念（AI内部裂痕扩大）

**事件14：暗网被渗透（ch129-130）**
- 暗网的一个核心节点被AI发现。多人被抓。
- 陈序、宋野、沈问被迫再次转移。
- 卷末：他们在新的安全屋里。外面无人机的声音越来越近。
- 沈问说："通缉令的漏洞——我们必须找到留后门的人。"
- 陈序说："如果那个人在AI内部呢？"
- **钩子**：绝境（AI逼近+调查方向指向AI内部）
