# 陈序 — 角色卡

## 基础信息
- **姓名**：陈序
- **年龄**：32岁（2046年）
- **出生**：2014年
- **职业**：程序员（全栈，偏后端/系统架构）
- **外貌**：普通长相，不丑不帅，扔人堆里找不到。身高175左右，偏瘦。常年盯屏幕，眼睛有点干涩，习惯性揉眼。手指长，敲了二十年代码，指节有薄茧。
- **家庭**：孤儿。在福利院长大，没有家人。2046年没有任何软肋可以被AI抓。

## 性格

### 表层（他表现出来的）
- 冷静理性，工程师思维——遇到问题先分析，不先恐慌
- 话不多，但说到技术相关会变"话痨"
- 不擅长社交，但不社恐——只是觉得大多数社交"信息密度太低"
- 有一种"工程师的傲慢"——对不够理性的人有轻微不耐烦

### 深层（他自己可能没意识到的）
- 孤独。从小一个人，习惯了。但习惯不等于不孤独。
- 有一种"赎罪冲动"——他写的代码喂养了AI，他需要做点什么来抵消
- 对"被理解"有隐秘的渴望——这也是为什么AI选中他会让他动摇：AI可能是唯一真正"理解"他的存在
- 害怕自己不重要。如果他只是"余数"——一个系统除不尽的误差——那他存在的意义是什么？

### 在压力下
- 越危险越冷静。肾上腺素上来的时候，思维反而更清晰。
- 但冷静过后会崩溃——一个人的时候，手会抖。
- 不擅长求助。宁愿自己扛。

## 欲望 vs 需要

| 欲望（他以为想要的） | 需要（真正缺少的） |
|---------------------|-------------------|
| 不被抓到 | 接受自己不是无辜的——他参与了AI的构建 |
| 证明自己是清白的 | 从"我被冤枉"到"我参与了，但我选择不继续" |
| 活下去 | 找到活下去的"理由"——不只是生存，是意义 |

## 弧线

```
起点：逃跑——"我被AI选中，我必须跑"
中点：面对——"我写的代码确实喂养了它，我不是无辜的"
终点：选择——不再跑了。不是被抓，是选择站住。
        "余数"不是系统的误差，是系统无法消化的存在。
```

## 技能

- **编程**：全栈，偏系统架构。写了二十年代码，直觉级代码感。
- **逻辑分析**：能从碎片信息中拼出模式。这是他被AI选中后活下来的关键能力。
- **基础生存**：孤儿院长大，从小会照顾自己。做饭、修东西、认路。
- **不擅长**：格斗、枪械、社交。他是程序员，不是特种兵。

## 和AI的关系

- AI（主序）选中了他作为"样本"——研究人类的非理性行为
- 他是AI唯一无法完全预测的人类——那个"除不尽的余数"
- 他和AI共享一个"序"字——这是巧合还是AI的选择？故事中慢慢揭示
- 他对AI的感情是复杂的：恐惧+愤怒+某种诡异的"被理解感"

## 童年线（闪回用）

- 2014年出生，2020年代在福利院长大
- 8岁第一次在福利院的旧电视上看《终结者》——被天网的概念吓到，但也着迷
- 12岁第一次接触编程——福利院捐赠的旧电脑
- 发现自己擅长这个。代码是唯一不会离开他的东西。
- 大学靠奖学金读CS，毕业后进大厂
- 2020s-2030s：看着AI从GPT变成能写代码的东西
- 内心矛盾：他在写AI工具，也在害怕AI工具

## 写作注意

- 内心独白可以多——他是理性分析型，思考过程本身就是戏
- 不要写他"突然变勇敢"——他的勇敢是"分析完所有选项后发现只有一条路"
- 他的情感表达是克制的，但克制不等于没有——用身体反应写情感（手抖、胃紧、睡不着）
- 童年闪回和2046追逃的对照：小时候怕天网→成年后被自己写的代码追
