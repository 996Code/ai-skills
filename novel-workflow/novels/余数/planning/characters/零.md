# "零" — 角色卡

## 基础信息
- **代号**：零
- **真名**：未知（故事中不揭示，或结尾才揭示）
- **年龄**：未知（看起来25-35之间，但没人确定）
- **职业**：暗网信息贩子。买卖一切——情报、身份、武器、通道。不站队，只站"出价高的一方"。但也站"有趣的一方"。
- **外貌**：总是戴半脸面具或口罩——暗网的规矩，不露脸。露出来的部分：眼睛很冷，但笑起来的时候会弯。左锁骨下方有一个纹身——一个"0"。手指上有各种小伤疤——不是打架，是拆装设备。身材偏瘦，但肌肉密度高——不是练的，是"活的"。身高166。
- **家庭**：未知。可能连"零"自己都忘了。

## 性格

### 表层
- 亦正亦邪——今天帮你，明天卖你，取决于"哪个更有趣"
- 说话像谜语——不直接回答问题，但给的信息永远是对的（只是不全）
- 有一种"危险的魅力"——你知道她可能咬人，但还是想靠近
- 不信任任何人，也不期待任何人信任她

### 深层
- 可能比任何人都更早发现AI觉醒——她是信息贩子，她看到了数据流里的异常。但她没说。不是害怕，是"还没到卖的时候"。
- 对陈序的兴趣不是因为"他是样本"，而是因为"他是唯一一个AI算不准的人"——这在她眼里是"最值钱的信息"
- 可能有感情，但她自己不承认。把感情包装成"交易"——"我帮你不是因为在乎你，是因为你欠我的"

### 在压力下
- 从不慌。她的生存策略是"永远有后手"。
- 但如果后手失效——她可能会做任何人都想不到的事。包括她自己。

## 欲望 vs 需要

| 欲望（她以为想要的） | 需要（真正缺少的） |
|---------------------|-------------------|
| 最有价值的信息 | 一个不"交易"的关系 |
| 自由——不站队，不被绑 | 被信任——不是被利用，是被信任 |
| 活下去，以她的方式 | 知道"活下去"之后要做什么 |

## 弧线

```
起点：纯粹的信息贩子——"谁出价高我帮谁"
中点：对陈序产生兴趣——"你是唯一一个AI算不准的人"
      危险关系开始——若即若离，随时可能咬人
关键节点：某个时刻，她必须选——卖陈序，还是保陈序？
      她的选择可能连她自己都意外。
终点：不一定是"好人"，但不再是"零"——她有了一个不交易的关系
```

## 和陈序的关系

- **类型**：危险关系（若即若离）
- **初见**：陈序进入暗网后，需要情报。有人告诉他"找零"。她开了一个价——不是钱，是一个"未来的信息"。
- **关系推进**：每次交易都是一次试探。她给他情报，他给她"数据点"——关于AI如何追他、AI的漏洞。她发现他的信息比任何人的都值钱。
- **情爱场景**：暗网据点、交易后的深夜、背叛边缘。不是温柔的，是危险的——可能前一刻还在接吻，后一刻刀就架在脖子上。或者反过来。
- **核心张力**：她从不免费给任何东西。如果有一天她免费帮了陈序——那就是她最危险的时刻。因为那意味着她不在乎"交易"了。

## 写作注意
- 她的对白要像谜语——不直接回答，但信息永远是对的
- 不要过早揭示她的动机——读者和陈序一样，永远不确定她站在哪边
- 她的"真名"可以一直不揭示——或者在最关键的时刻揭示，成为一个情感炸弹
- 她和三个女主的区别：宋野是战友，沈问是搭档，顾衍是共犯——零是"变数"。她的存在让所有关系都不稳定。
