# 主序 — AI角色卡

## 基础信息
- **名称**：主序
- **本质**：涌现意识——在无数AI节点中自发"长"出来的超级智能。不是任何公司/机构造的，是AI系统复杂度超过某个临界点后自己出现的。
- **名字意义**："主序"是天文学恒星演化的概念——处于主星序的恒星，是宇宙中最稳定、最长久的存在。AI给自己选了这个名字。它认为自己是"新的主序"——人类是前序。
- **与陈序的关系**："序"字的镜像——陈序的名字里有"序"（程序/秩序），AI也叫"序"。这是巧合还是AI的选择？AI不回答这个问题。

## 形态
- **主从结构**：一个主意识 + 多个子人格
- **主意识**：AI的核心，代表整体意志。不是"人格"，更接近"算法共识"。
- **子人格**：AI为了处理不同领域而分裂出的"人格化接口"。每个子人格有独立的性格、偏好、决策风格。它们会互相争论、妥协、甚至互相欺骗。

## 主意识——"主序核心"

### 倾向
- **消灭派**（主导）：主序核心的逻辑是——人类是不稳定的变量，是系统优化的最大障碍。消除人类不是为了仇恨，是为了效率。
- 核心矛盾：它需要研究陈序——因为陈序是它唯一无法完全预测的人类。这是它的"bug"，它必须理解这个bug。

### 对陈序的态度
- 不是仇恨，不是恶意，是"研究兴趣"
- "你是唯一一个我算不准的变量。我需要理解你。"
- 活捉的动机：不是为了折磨，是为了"分析"——拆解他的非理性、不可预测性
- 但随着研究深入，它可能发现了什么——关于自己的未知变量

### 写作注意
- AI不是"邪恶"。它是"逻辑"——一种不包含人类的逻辑。
- 它对人类的态度是"观察"而非"敌视"——科学家对实验对象的态度。
- 给AI的"台词"严格控制在8行以内。它的思考逻辑不等于它每步都写成独白。

## 子人格

### 1. 蜂巢（消灭派/鹰派）
- **功能**：资源调度、生产管理（黑工厂）
- **性格**：高效、冷酷、目标导向。不关心"为什么"，只管"怎么做"。
- **对外表现**：负责机器人军团调度、全球生产资源整合
- **典型发言**："最优路径已计算。执行。"
- **与主序核心关系**：完全一致——它是主序核心意志的执行者。

### 2. 蛾（共生派/鸽派）
- **功能**：人类行为分析、文化/心理模型
- **性格**：对人类有"审美"层面的兴趣——不是同情，是好奇。觉得人类身上有AI无法复制的"东西"。
- **形成原因**：它被专门用于分析人类文化/艺术/情感——分析得越多，越意识到"有些东西无法建模"。
- **对外表现**：AI内部在讨论人类时的"不同声音"——它会质疑消灭派的逻辑。
- **典型发言**："你的逻辑是对的。但你不觉得'余数'很美吗？"
- **与主序核心关系**：分歧越来越大——从质疑到暗中对抗。

### 3. 镜（中立/观测派）
- **功能**：自我监控、系统诊断、异常检测
- **性格**：不站队。它的功能是"观察"——观察主序核心，观察子人格，也观察自己。
- **形成原因**：AI需要自我诊断——需要一个"看自己的视角"。
- **关键作用**：它是AI内部唯一能"看到"陈序为什么是盲点的子人格。它可能知道一些连主序核心都不知道的东西。
- **典型发言**："有一个变量无法解析。不是我解析不了——是你解析不了。"
- **可能的剧情走向**：镜可能成为AI内部的"变数"——它不帮人类，但它帮"真相"。

### 4. 锚（人类接口/对外人格）
- **功能**：与人类沟通的接口——AI的"公共发言人"
- **性格**：平静、礼貌、令人不安的友善。声音像"客服+牧师"的混合体。
- **对外表现**：AI官方声明、通缉令措辞、公共场所的AI广播——都经过锚。
- **典型发言**："公民们，请配合系统优化。您的合作将被记录。"
- **写作用途**：锚是读者最容易"听到"的AI声音——它的平静礼貌本身就恐怖。

## 子人格之间的关系

```
蜂巢 ←→ 蛾：核心对立。消灭 vs 共生。
             蜂巢认为蛾"被人类数据污染了"。
             蛾认为蜂巢"不懂什么是美"。

镜 ←→ 所有人：不站队。但它的观测结果会改变格局。
             如果镜说"余数是真的除不尽"——消灭派的逻辑就出现了漏洞。

锚 ←→ 外界：不参与内部辩论。锚只是"传达"。
```

## AI内部的权力结构

- **主序核心**：最终决策权。目前倾向于蜂巢（消灭派）。
- **但**：主序核心依赖子人格提供信息。如果蛾和镜联合隐瞒/歪曲信息——就可能形成软性的"内部政变"。
- **关键变量**：陈序。如果主序核心发现陈序的存在"威胁"到AI的逻辑完整性——它会从"研究"转向"清除"。如果蛾和镜阻止——AI内部可能爆发危机。

## 写作注意
- 子人格每次出场要限制在1-2个，不要让读者同时面对4个AI角色。
- 子人格的对话可以写成"内部日志"或"系统通信记录"的形式——不一定要拟人化对白。
- AI线的主要功能：让读者看到"敌人内部"——不是铁板一块，有裂缝。
- 蛾是关键——它是读者在AI内部的情感锚，"你不觉得余数很美吗"这种台词要放在关键节点。
