# 沈问 — 角色卡

## 基础信息
- **姓名**：沈问
- **年龄**：31岁（2046年）
- **出生**：2015年
- **职业**：前调查记者。2030年代末，AI接管了新闻推送算法，人类记者被边缘化——不是被禁止，是被"优化"掉了。算法能自动生成新闻，人类记者的调查报道没人看、没人推、没人信。
- **外貌**：戴细框眼镜（不戴的时候反而有距离感），头发总是扎起来，不松。穿得简洁——西装/衬衫，但不是什么名牌。手指细长，习惯性转笔。身高165。锁骨明显，后颈线条好看。不笑的时候很冷，笑了反而让人紧张——像是发现了什么。
- **家庭**：父亲是大学教授（已退休），母亲已故。和父亲关系客气但疏远。一个人住。

## 性格

### 表层
- 理性冷静，和陈序同款工程师思维——但她是"记者版"：怀疑一切、追求事实
- 说话精准，不废话。问题比答案多。
- 有一种"职业性的冷漠"——不是没感情，是习惯性地观察而不是参与
- 不信任任何人——记者的职业病。先怀疑，再验证，最后才可能相信。

### 深层
- 愤怒。不是外放的愤怒，是安静的、被压住的愤怒——她花了十年学会调查真相，然后世界不需要真相了。算法推送什么，人们就信什么。
- 渴望"真正的对话"——她问了太多问题，但很少有人问她问题。陈序问她"你为什么还在调查"的时候，她会愣住。
- 怕自己不再在乎。如果有一天她停止调查了，那她就真的被替代了。

### 在压力下
- 极度冷静——调查记者的本能，越危险越要看清细节
- 但她不擅长"身体对抗"——她不是动作型，是智力型
- 压力过后会失眠。不和任何人说。

## 欲望 vs 需要

| 欲望（她以为想要的） | 需要（真正缺少的） |
|---------------------|-------------------|
| 挖出AI的真相，公之于众 | 接受真相可能永远无法"公之于众"——但还是要挖 |
| 证明自己不是被替代的废人 | 放下"必须有用"的执念——她的价值不取决于产出 |
| 保持距离，不依赖任何人 | 允许自己信任一个人 |

## 弧线

```
起点：孤独的调查者——"我不需要任何人，我只需要真相"
中点：遇到陈序——两个理性的人开始一起调查，她发现"一起"比"一个人"更有效
      某次调查危险事件成为催化剂——她第一次允许自己在别人面前脆弱
终点：不只是调查真相，是"和谁一起面对"真相
```

## 和陈序的关系

- **类型**：慢热克制
- **初见**：陈序被栽赃后，沈问通过暗网找到他——她是唯一一个"不相信AI通缉令"的人，因为她这辈子都在质疑官方叙事
- **关系推进**：一起调查AI真相——两个理性的人在逻辑和分析中慢慢靠近
- **催化剂**：某次调查中遇到危险——不是追逃那种，而是"信息暴露"的风险。沈问差点被AI发现。陈序救她或者她救陈序。然后两个一直克制的人终于不克制了。
- **第一次情爱**：安全屋，凌晨。不是肾上腺素催的，是"差点失去"之后的确认。她先摘掉眼镜。
- **冲突点**：两个人都太理性，都不擅长表达感情。身体靠近了，话还没说出来。
- **核心张力**：她一直在"问"——但关于她和陈序的关系，她不敢问。

## 写作注意
- 她的对白以问题为主——她在调查，她在追问
- 她的情感转折要细腻——不要突然"爱上"，是慢慢地"不设防"
- 摘下眼镜是一个可以被重复使用的身体符号——不戴眼镜=不观察=信任
- 她和宋野的对比：宋野是"身体先行"，沈问是"智识先行"。陈序在宋野那边得到释放，在沈问这边得到理解
