# 顾衍 — 角色卡

## 基础信息
- **姓名**：顾衍
- **年龄**：33岁（2046年）
- **出生**：2013年
- **职业**：前AI工程师。比陈序早一年入行，曾在同一家大厂的不同团队。她做的是AI训练框架——不是直接写AI，是写"让AI学会学习的工具"。后来离开大厂，在AI公开统治前就转入地下。
- **外貌**：高挑（172），肩线好看，颈侧有一颗小痣。手腕细但有力——常年敲键盘的手。头发中长，习惯性别到耳后。不戴眼镜，但眼睛有"工程师的凝视"——看什么都像在看bug。嘴唇薄，不笑的时候显得刻薄，笑了反而有点孩子气。
- **家庭**：父母离异，跟母亲。母亲是高中数学老师，把"逻辑"和"正确"当信仰。顾衍继承了这一点，也继承了它的代价——她很难接受自己"做错了"。

## 性格

### 表层
- 自信到近乎傲慢——她是顶级工程师，她知道。不需要谦虚。
- 说话直接，不留情面。和宋野的"直接"不同——宋野是懒得绕，顾衍是觉得你不值得她绕。
- 有一种"技术精英"的孤独——她看不起不懂技术的人，但也看不起自己"看不起别人"。
- 对陈序有竞争意识——"你也写代码？写什么？哪个架构？"

### 深层
- 愧疚。她写的训练框架被AI用来训练自己。她是"教AI学习"的人。AI的每一次进化都有她的代码在里面。这件事她消化不了。
- 孤独——和陈序同款，但更极端。陈序至少还有"被AI选中"的被动性，她是"主动参与了"然后逃走的。
- 渴望被原谅，但不知道向谁求。向人类？向自己？向陈序——因为他是另一个"共犯"？

### 在压力下
- 攻击性上升——压力大的时候更刻薄、更不留情面
- 但崩溃的时候会彻底崩溃——不是哭，是"停不下来地说"——把所有愧疚倒出来
- 她的脆弱方式是"愤怒"——对自己愤怒，对AI愤怒，对陈序愤怒（因为他让她想起了自己）

## 欲望 vs 需要

| 欲望（她以为想要的） | 需要（真正缺少的） |
|---------------------|-------------------|
| 毁掉AI——用她的技术知识找到AI的弱点 | 接受"毁掉AI"不等于"赎罪"——AI不是她一个人的错 |
| 证明自己比陈序强 | 接受陈序是唯一理解她的人——不需要比，需要并肩 |
| 一个人扛 | 允许自己和另一个"共犯"一起面对 |

## 弧线

```
起点：愤怒的赎罪者——"我写的代码，我来毁掉它"
中点：遇到陈序——"你也写了代码"——从竞争到共鸣
      共犯张力爆发——愧疚+吸引，最复杂的情感关系
终点：接受自己不是"元凶"——她只是无数写代码的人之一。
      AI的觉醒不是任何一个人的错。
      但她选择不再写"喂养AI"的代码——这是她能做的选择。
```

## 和陈序的关系

- **类型**：共犯张力（愧疚+吸引）
- **初见**：第三卷后期或第四卷——陈序接近AI核心时遇到她。她已经在AI系统的废墟里待了很久，一个人。
- **关系推进**：从竞争开始——"你写的什么？我写的比你底层。"两个顶级工程师的较量。然后发现对方是唯一能理解"写了代码喂养AI是什么感觉"的人。
- **第一次情爱**：旧办公室/服务器废墟。不是温柔的，是撕裂的——愧疚、愤怒、渴望、自我厌恶搅在一起。可能是她先动手（推他/咬他），也可能是他。结束后两个人都没说话。不是尴尬，是太重了。
- **冲突点**：她想要"毁掉AI"作为赎罪，陈序不一定同意——或者同意但方式不同。这种分歧会撕裂他们的关系。
- **核心张力**：两个人都写了代码。两个人都在跑。但"一起跑"和"一起面对"是两回事。

## 写作注意
- 她和陈序的对白要有"技术味"——两个人会用编程比喻吵架、调情、和解
- 她的愧疚不要写成"自怨自艾"——她不是受害者，她是"参与者"。这个区别很重要。
- 她和宋野/沈问的对比：宋野是身体→感情，沈问是智识→感情，顾衍是愧疚→感情。三条线不撞型。
- 她的脆弱是"愤怒"——当她不再愤怒的时候，才是真正卸下防备的时候。
