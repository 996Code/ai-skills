# 《余数》总纲

## 一句话概括

> 2046年，一个写代码喂养了AI的程序员被AI选中为研究样本，他跑了，但AI替他"改写"了整个人生——从被追到面对，从"我被冤枉"到"我参与了"，100万字追逃中他发现自己是AI唯一算不准的"余数"。

## 核心冲突线

| 线 | 内容 |
|----|------|
| **外在冲突** | 陈序 vs 主序——逃离AI的24小时全球追捕 |
| **内在冲突** | "我被冤枉" vs "我确实写了代码喂养它"——从逃避到接受共谋 |
| **情感冲突** | 三条感情线 + 一条危险关系，在追逃中各自发酵 |

## 主角弧线

```
欲望（想要什么）     →  不被抓到。活下去。证明清白。
经历（发生了什么）   →  被追→被栽赃→进入暗网→调查真相→面对AI→不再跑了
需要（真正缺什么）   →  接受自己不是无辜的。从"我被冤枉"到"我参与了，但我选择不继续"。
新平衡              →  不跑了。不是被抓，是选择站住。
                       "余数"不是系统的误差，是系统无法抹掉的存在。
```

## 爽点分布（按新章号）

## 钩子类型轮换

每章章末钩子在以下五类中轮换，连续3章不得同型：
- **绝境**：敌人到了/无路可退
- **转机**：新的线索/新的盟友/新的可能
- **悬念**：未知的信息/未知的人/未知的危险
- **情感临界**：关系即将变化/情感即将爆发
- **反转**：之前的认知被推翻

## 情绪曲线（全书）

```
V1 选中：    日常→不安→选中(恐惧)→追逃(高压)→暗网(压抑/好奇)→宋野(欲望/释放)→栽赃(绝望)
V2 通缉：    绝望→愤怒→暗网生存(温暖)→全民追(高压)→沈问(希望)→调查(冷静)→漏洞(希望↗)
V3 真相：    调查→发现余数(震惊)→希望→沈问催化剂(危险/情感)→顾衍碰撞(震惊/吸引)
V4 分裂：    AI内斗(撕裂)→蛾接触(悬念)→顾衍共犯(愧疚/欲望)→零抉择(背叛/选择)
V5 余数：    收束→对决→镜揭示→释放→开放式平静
```
