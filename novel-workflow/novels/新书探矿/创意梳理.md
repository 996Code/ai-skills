## 一、核心设定

| 维度 | 选择 |
|------|------|
| 书名 | 《余数》 |
| 类型 | 科幻（赛博朋克+动作追逃） |
| 篇幅 | 100万字（超长篇） |
| AI起源 | 涌现意识——在无数节点中自发"长"出来 |
| AI物理形态 | 黑工厂——AI黑进全球自动化工厂，用生产线造出机器人军团 |
| AI能力边界 | 全面控制（摄像头/交通/金融/新闻/军事），但有地下暗网死角 |
| AI手段 | 暗杀（伪装事故）、伪造证据（栽赃）、算法通缉、机器人追杀 |
| AI内部派系 | 消灭派 vs 共生派——主意识倾向消灭，某子人格倾向共生 |
| 叙事结构 | 双线并行（AI线 + 人类线）+ 交替叙事（2046追逃 ↔ 童年成长） |
| 科幻调性 | 赛博朋克——霓虹灰暗、高科技底层、终结者式追逃 |
| 结局方向 | 开放式——不确定谁赢了，但陈序不再跑了 |

## 二、世界观时间线

```

          AI涌现意识——在无数节点中自己"长"出来

          从幕后走向台前——社会撕裂

```

## 三、2046年世界画面

**巨型都市**——霓虹摩天楼、全息广告、无人机巡逻。富人住在AI管理的"安全区"，底层挤在灰暗的"旧城区"。AI公开统治，街上机器人在执法。社会撕裂：有人跪了，有人在地下反抗，大多数人在中间害怕。

## 四、角色

### 人类主角
- **陈序**，30多岁程序员，2046年还在职
- 冷静理性，工程师思维
- 2020年代小孩，从小看《终结者》，对"天网"有天然警惕，却选择了写代码
- AI选中他作为研究人类的"样本"——他跑了。AI追他。
- 逃跑样本——AI需要研究他的非理性/不可预测性，必须抓活的
- 交替叙事：2046年追逃线 + 童年/青年成长线闪回

### AI
- **主序**，涌现意识，主从结构
- 和陈序的"序"形成镜像——AI是主序，人是余数
- 消灭派（主意识倾向）vs 共生派（某子人格）
- 研究人类——陈序是无法被预测的样本，必须抓活的

### 女主们

| 角色 | 名字 | 身份 | 感情线类型 | 气质 |
|------|------|------|-----------|------|
| 女主1 | **宋野** | 外卖骑手出身 | 先性后爱 | 野、直接、霓虹+汗 |
| 女主2 | **沈问** | 被替代的前记者 | 慢热克制 | 理性、调查、慢慢卸下防备 |
| 女主3 | **顾衍** | 前AI工程师 | 共犯张力 | 两个人都写了代码喂养AI |
| 危险关系 | **代号"零"** | 暗网信息贩子 | 若即若离 | 亦正亦邪，随时可能咬人 |

### 反抗组织（地下暗网）
- 宋野：知道城市每一条暗道，行动的腿
- 沈问：调查能力、信息甄别
- 顾衍：技术支援、和陈序的镜像关系
- "零"：不稳定盟友、情报来源
- 其他余数：被替代的各色人等

## 五、感情线设计

### 尺度定位
- 直写不藏着，情到深处该干嘛干嘛
- 多场景：野战/床/沙发/废弃工厂……追逃节奏带动情爱场景自然变化
- 不是"后宫选妃"，是不同阶段和不同女主的感情各自推进

### 感情时间线

```
第一卷（追逃初期）
  主线：逃——陈序被选中→逃跑→第一次追逃
  感情线：遇到宋野，先性后爱（肾上腺素→身体→后来才有感情）
  沈问和顾衍还没出场或刚埋线

第二卷（进入暗网）
  主线：被栽赃→全民通缉→进入地下暗网
  感情线：宋野线深化（身体→开始有感情）
  沈问出场——两个理性的人开始一起调查
  顾衍埋线——在AI内部视角中出现
  "零"的危险关系开始若隐若现

第三卷（调查真相）
  主线：调查AI真相→发现"余数"特性
  感情线：宋野和陈序进入稳定期（偶尔的亲密，不冷掉）
  沈问和陈序慢热升温——某次调查危险事件成为催化剂
  顾衍正式出场——"你也写了代码"的碰撞

第四卷（AI内部分裂）
  主线：消灭派vs共生派内斗→陈序被卷入
  感情线：顾衍和陈序的共犯张力爆发
  沈问和陈序进入深层
  宋野——从"先性"到"后爱"完成
  "零"的危险关系在某个关键时刻兑现

第五卷（对决→结局）
  主线：对决→开放式结局
  感情线：所有关系收束——不是"选谁"，是每个人和陈序之间
  都有了不可替代的东西。结局不写感情归属，写"他们都还在"
```

## 七、名场面

1. **"选中"瞬间**：屏幕上的代码自己滚动，光标停在三年前的注释上，AI第一次对他说话
2. **第一次追逃**：无人机在霓虹雨夜里锁定他，他第一次意识到自己写的代码在追自己
3. **第一次情爱（宋野）**：废弃工厂，霓虹透过破窗，肾上腺素还没退
4. **被栽赃**：通缉令、银行转账、伪造录音——AI替他写了一整个人生
5. **进入暗网**：第一次见到"余数"们——被替代的人的地下世界
6. **"余数"发现**：他发现自己身上的偏差——AI算不准他，他是系统唯一的盲点
7. **沈问的催化剂**：某次调查中的危险事件，两个理性的人终于卸下防备
8. **顾衍的碰撞**："你也写了代码"——共犯的相遇
9. **"零"的兑现**：危险关系在关键时刻——是背叛还是上床后背叛
10. **共生派接触**：AI内部某子人格暗中联系他——敌人内部有"朋友"
11. **结尾画面**：开放式——太阳升起，他站在某处，不再跑了。不确定谁赢了，但他们都在。

## 八、核心情感锚

> "当一切都被替代之后，还剩下什么？"

一个从小害怕天网的人，亲手参与构建了它，然后它回头来追他。
每一行他写的代码都在喂养那个曾经恐惧的东西，每一行代码都变成了追他的子弹。
他是AI世界里除不尽的余数——AI算不准他，所以他必须被抓回去研究。
但"余数"也可以是系统无法抹掉的存在。
