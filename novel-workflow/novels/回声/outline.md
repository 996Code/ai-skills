# 回声 · 大纲

## 总纲

### 一句话概括
一个声学工程师回到母校调查"幽灵回声"，发现真相不是鬼而是物理——但物理背后藏着一个人的遗言。

### 核心冲突线
科学解释 vs 人性真相——每次科学解释都逼近一个更深的真相：教授不是意外地留下了声音，是刻意地选择了永生

### 主角弧线
- 起：回避（"我只是来做检测的"）
- 承：逼近（科学数据把真相一层层剥开）
- 转：直面（录音最后一句话是对他说的）
- 合：释然与怅然（回声还在继续，他选择不关掉它）

### 叙事框架映射：起承转合
| 阶段 | 章节 | 内容 | 情绪走向 |
|------|------|------|---------|
| 起 | 第1章 | 回校+首次听到回声 | 冷→好奇→微惧 |
| 承 | 第2-3章 | 测量+发现异常+找手稿 | 专注→疑惑→不安 |
| 转 | 第4章 | 拆解共振系统，发现录音 | 震惊→动摇→心痛 |
| 合 | 第5章 | 听完录音+离开 | 释然→怅然→余韵 |

### 情绪曲线
```
好奇 ──→ 专注 ──→ 疑惑 ──→ 震惊 ──→ 心痛 ──→ 释然 ──→ 怅然
 ↗       ↗       ↗       ↗↗      ↗↗↗    ↘       ↘↘
```

## 章纲

### 第1章：归声（目标字数：1200字）

场景列表：
1. 开场——林北辰走在熟悉的老校区路上（感官：南方潮湿的空气、老樟树的味道）
2. 见周敏——基建处办公室，周敏催促解决"闹鬼"问题
3. 进入旧楼——走廊里的回声（普通回声，铺垫302的特殊）
4. 进入302室——第一次听到"幽灵回声"（教授的声音片段）

章末钩子：回声说的那句话——"小林……你来了吗？"
伏笔标注：fs004（手机未接来电）

情绪走向：冷（刻意疏离）→ 奇（第一次听到）→ 惊（回声居然叫了他的名字）

---

### 第2章：共振（目标字数：1500字）

场景列表：
1. 写前回忆——林北辰梦到2006年的那个电话（缓冲带：温暖回忆插入冷调查中）
2. 携设备进302测量——发现完美共振腔的参数
3. 发现频率异常——回声中有不属于驻波的成分
4. 周敏催促拆除——"工期不等人"

章末钩子：频率数据指向一个结论——回声里不是纯粹的物理反射，有人播了录音进去
伏笔标注：fs001（窗户朝西/阳光时段）、fs002（教授手稿）

情绪走向：专注→疑惑→不安

---

### 第3章：手稿（目标字数：1500字）

场景列表：
1. 去旧办公室找教授遗物——抽屉里发现频率手稿
2. 分析手稿——教授标注了302室的共振频率，精确到小数点后三位
3. 频率匹配——手稿上的频率=302室异常回声的频率
4. 进入302再次测量——发现隔板有异响（fs005伏笔）

章末钩子：教授知道302的声学秘密，而且他利用了它——这不是意外，是设计
伏笔标注：fs003（频率不匹配的额外一句话）、fs005（隔板背面刻字）

情绪走向：专业冷静→逐渐动摇→"他不是无意留下的"

---

### 第4章：拆解（目标字数：1500字）

场景列表：
1. 决定拆解共振系统——物理方法验证
2. 拆开木质隔板——背面刻着一行字："我最后的实验"
3. 发现录音设备残迹——旧式磁带播放器，接在共振腔的入口
4. 回声中的录音内容被提取——教授的声音完整版

章末钩子：录音最后五秒——教授的声音变了，不再是缓慢的学术语调，而是急促的、像在对一个人说话
伏笔标注：fs003回收（频率不匹配的那句话）

情绪走向：理性（拆解）→ 震动（发现"我最后的实验") → 心痛（理解教授的意图）

---

### 第5章：余响（目标字数：1300字）

场景列表：
1. 清晨回到302——林北辰一个人坐在共振腔里
2. 听录音最后一段——教授说："小林，如果你听到了……那就说明我算对了。我没等到你，但我让声音等了。嗯……二十年了，够久了吧？"
3. 林北辰的沉默——没有哭，没有说"对不起"，只是坐在那里
4. 离开旧楼——走到楼下，回头看窗户，阳光穿过玻璃打在302的墙上，回声还在继续
5. 结尾——林北辰给周敏发了邮件："302室没有鬼。建议保留。"

章末钩子：（开放式结尾）邮件最后附了一行字——"有些声音，拆不掉。"
伏笔标注：fs005回收（隔板刻字="我最后的实验")

情绪走向：平静→微动→释然→怅然

## 大纲验证

1. ✅ 特定性测试：每章有具体场景+情绪走向+钩子
2. ✅ 伏笔覆盖：5条伏笔全部有埋设和回收章节
3. ✅ 角色弧线：回避→逼近→直面→释然
4. ✅ 价值转换：每章都有（无知→知识/回避→直面/理性→情感/恐惧→理解）
5. ⚡ 短篇简化：不检查黄金三章和情绪曲线平坦区
