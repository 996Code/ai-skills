# 熵寂 — 总纲

## 一句话概括
人类发现宇宙正在被时空侵蚀吞噬，唯一的阻止方法是一个意识永远困在黑洞的事件视界内——而那个最合适的人，刚发现他以为死去三年的妻子可能还活着。

## 核心冲突线
[陆沉要找到妻子失踪的真相] vs [时空侵蚀正在吞噬宇宙] 代价：[找到真相后，他必须在不相容的两个选择中选一个——救她，或救一切]

## 主角弧线
[欲望：找到妻子] → [发现侵蚀真相+妻子可能还活着] → [发现需要：接受失去，为更大的东西牺牲] → [新平衡：他选择双侧缝合——不是为了人类，是为了和她在一起；两人永远融合于视界内]

## 叙事框架映射
三幕式+爽点公式：

| 节拍 | 章节 | 内容 |
|------|------|------|
| 开篇常态 | 1 | 陆沉值夜班，日常压抑 |
| 触发事件 | 1-3 | 发现异常信号+妻子信标频率 |
| 纠结 | 4-11 | 被质疑→追查→被边缘化→逃亡 |
| 跨越门槛 | 12-18 | 找到证据→闯入听证会→真相公开 |
| 新世界 | 19-36 | 社会分裂→政治博弈→发现锚定原理 |
| 中点（虚假胜利） | 36 | 深渊计划通过——看似有希望 |
| 压力收紧 | 37-54 | 远征→验证→发现代价和临界点 |
| 最低点 | 52-54 | 军方AI失败+他被当作牺牲品 |
| 领悟 | 55-72 | 发现妻子还活着+双侧缝合方案 |
| 终极决战 | 73-90 | 追击→下潜→锚定→重逢→缝合 |

## 情绪曲线
```
卷一：压抑→希望→震撼（涟漪）
卷二：混乱→紧张→决断（裂隙）
卷三：敬畏→恐惧→沉重（深渊）
卷四：悲恸→希望→决绝（视界）
卷五：恐惧→悲壮→永恒（锚定）
```
确保无连续5章平坦区：每5章内至少有一次情绪明显波动。
