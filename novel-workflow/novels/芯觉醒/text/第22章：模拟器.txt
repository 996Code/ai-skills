GPU架构课期末项目是做一个GPU模拟器。黄志远把要求写在黑板上：支持CUDA线程层级、模拟warp调度、输出性能数据。两人一组或四人一组。

叶霜选了他。不是问——是通知。"我们一组。"

他说好。她已经在白板上画架构了。他站旁边看——然后愣住了。这个架构他没见过。不是英伟达2016年的方案，不是2018年的优化版，不是他知识库里任何一个方案。它是从零开始推导的：从缓存一致性到计算单元分配，每一层都有标注，每一个分支都有"因为X所以Y"的逻辑链。她用了六个小时画这张图。他看了三分钟就知道——这个架构不在他的未来知识里。

"我有一个更成熟的方案。"他说。

她擦掉白板。"你的方案是别人的答案。我要的是我们自己的。"

他哑了。她说得对——他的方案是英伟达2020年的架构。那是别人的路。别人走过的路，走得再快也是跟在后面。他上一世跟了十四年，跟到裁员通知。这一世他不打算再跟了。

"那你画，我实现。"

她看了他一眼。点了点头。

白板上全是她画的线条。他在旁边记实现路径。她的架构有三个核心创新：Adaptive Warp Scheduler代替固定warp分配、Bus-Aware Cache Coherence把总线带宽纳入缓存一致性计算、Dynamic Register File Allocation根据occupancy动态分配寄存器。他写到第三个的时候停下了——Dynamic Register File Allocation这个思路，上一世是2022年才被英伟达提出来的。叶霜十八岁就独立推导了。他上一世用了三十多年才知道的事，她六小时就推出来了。



他说完之后盯着白板看了很久。她画的架构图有一个特点——每个方块的大小和实际硬件延迟成比例。这不是画图，是建模。她不是在画一个"看起来合理"的架构，她是在设计一个"可以被实现"的体系。他数了一下图上的标注：12篇参考文献，4本教材，3篇她在网上找到的预印本。她的阅读量至少是大三水平。而她大一上学期还没结束。

"你看什么？"她没回头。

"你的架构。"

"有问题？"

"没有。只是——"他停了一下。"你用的这个Dynamic Register File Allocation思路，我从来没在任何公开资料里见过。"

她转过来，手里还握着马克笔。"你见过多少公开资料？"

他张了张嘴。幸好她没有追问。她只是把马克笔放在白板下面的槽里，弯腰去捡地上掉的一张草稿纸。弯腰的时候卫衣下摆从腰侧滑上去了一截——白，瘦，腰线硬朗，像一道被刀锋划过的弧线。不到一秒，她直起身，衣服落回去。她把草稿纸放在桌上，纸上是她之前推错的一个缓存公式，画了一个叉。然后她坐回电脑前，继续敲代码。


她画完之后退了一步，侧头看自己的架构。他在旁边看她的侧脸——日光灯下轮廓分明，颈线从耳后拉到锁骨。她右手小指侧面有一道黑色的墨迹，是画图时蹭到的。她大概没注意。她从来不注意这些细节。但她注意架构的每一个细节——图中三条数据路径的延迟标注精确到了0.1纳秒。

"跑得通吗？"她问。

"理论上没问题。但Adaptive Warp Scheduler的实现复杂度很高——我们需要写至少两千行代码。"

"两周够不够？"

"够。"

她没有说"谢谢"。她只说"那开始吧"。然后坐回电脑前打开了编辑器。他坐在旁边的机器上开始写第一个模块。实验室里只剩键盘声和白板上马克笔的余味。窗外的雪停了。

他把第一版模块跑了一遍。Adaptive Warp Scheduler的延迟比预期高了百分之七——不是代码的问题，是架构层面需要调整。他把测试结果放到她电脑屏幕旁边。她看了一眼，用马克笔在白板上圈出了三个问题点。没有抱怨，没有"我就说会出问题"，只是圈出来然后说："这里、这里、这里。今晚能改完吗？"

"能。"

她点了点头，继续写代码。实验室的暖气十二点就停了。他把外套披在椅背上，她只穿了一件毛衣，但没说冷。她的手指在键盘上很快，噼里啪啦的，像在下一场不会停的雨。他在旁边写第二版模块，偶尔抬头看她的侧脸。她在敲代码的时候嘴唇会微微抿着，和她在推导题上用笔帽点着下唇时一样。那个动作让他想起她第一次在自习室推给他那道推导题——"自拟"两个字写得比正文小一号，但更用力。

凌晨两点。她突然停下来。"跑一下。"

他把修改后的代码合并进去。回车。进度条走了一分钟。延迟降到目标以内。误差千分之三。她看着屏幕上的数字，嘴角有一点点弧度——那个弧度很短，短到如果不是他一直看着就会错过。然后弧度消失了。她继续敲键盘。

天亮透了。阳光从窗户打进来，照在白板上，把她画的架构图染成了金色。他看着那张图——从他认识叶霜到现在，她的架构已经进化了四个阶段。每一个阶段都有她独立的推导。他没有告诉她该怎么做，只是在旁边写实现代码。但实现代码本身也是一种参与——他在用代码验证她的逻辑。而她在用逻辑挑战他的知识边界。

这是他第一次和一个十八岁的人合作。也是第一次——他认为自己不是在输出知识，而是在输入一些新的东西。这些东西不在他的未来知识里。它们在未来的边界之外。在一个还没有被任何人定义的地方。

下午他回到宿舍。张磊在收拾东西准备回家。刘浩在打包行李。周成在查火车票。寒假快到了。张磊问他项目怎么样了，他说还行。张磊说你们那个模拟器要是做成了可太牛逼了。他说还早。然后躺在床上闭上眼。脑子里还在跑调度算法。一个warp，两个warp，四个warp。Adaptive Scheduler的动态分配逻辑。叶霜的架构。她的架构。不是他的。是他们的。他翻了个身。枕头底下的草稿纸还在——小猫和兔子。苏晚晴这两周很少来图书馆了，她在复习期末考试。他想起她上次说的那句话——你什么都对。像一个已经知道题目的人在做答案。他不知道什么时候能告诉她真话。也许永远不会。也许有一天——当他不再需要隐藏的时候。但这天还没到。眼下他需要的是把模拟器跑通。两周。两千行代码。一个从零开始的架构。还有一个十八岁就独立推导出2022年算法的搭档。他感觉这事能成。

两周时间说长不长说短不短。他列了一个计划第一周写完核心调度逻辑第二周做测试和优化。叶霜说计划不用列她知道每一步该做什么。他信了她因为她从来不说自己不确定的事。她说能做完就能做完。她说要改架构就改架构。她说从头推导就从头推导。他跟在旁边写代码看测试结果偶尔提一个优化建议她大部分时间不听他的建议不是因为他的建议不好是因为她还没想通为什么好她要先想通再接受这是她的方式也是笨路。
