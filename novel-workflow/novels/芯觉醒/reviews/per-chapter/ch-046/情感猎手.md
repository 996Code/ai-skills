# 情感猎手 — 第46章：产品demo

## 情绪走向
- **疲惫（连续三个通宵，眼下青色）** → **专注（铅笔盘发，手指凉）** → **释放（凌晨两点全部跑通）** → **收敛（"可以了"两个字）** → **庆祝（张磊二十个感叹号，刘浩加页数）** → **确认（秦岚"我明天带合同来"）** → **燃烧（英伟达评审会，美国架构师"跑了两年"）** → **胜利（沈灵"你们赢了"）** → **升级（秦岚带合同，三千万）** → **前瞻（叶霜画"下一代架构预研"）** → **确定的安静（结尾循环"和昨天一样"）

## 角色情感
- **叶霜**：本章叶霜的情感藏在极限状态里。连续三个通宵→眼下青色是毛细血管破裂→不是卖惨，是写专注的代价。铅笔盘发→"不是新铅笔，是画架构图用旧的那支"→连找发绳的时间都不愿意浪费。凌晨两点全部跑通→看白板→"可以了。"→两个字。不是激动，是确认。秦岚带合同来→她没看合同，在白板上画"下一代架构预研"→"以后不能等现在跑慢了再开始。"→全书最叶霜的时间观——现在和以后同时进行。
- **陈默**：本章陈默的情感藏在观察里。发现叶霜手指温度规律→画架构图时凉，跑通后暖→"他递了大概二十次咖啡之后发现了一个规律"→全书最细腻的观察——用二十次递咖啡发现一个人的生理规律。收到沈灵"你们赢了"→没回→截图发407群→用行动替代语言。结尾盯天花板裂纹→"命运不是一只蝴蝶。命运是一个人。或者两个人。或者六个人。"→全书最精确的命运定义。
- **秦岚**：本章秦岚的情感藏在身份转换里。电话里安静十五秒（比上次多五秒）→"我明天带合同来。"→从"追加"到"正式投资协议"。说"不是我赌赢了。是你们跑通了。"→从赌徒变合作者——语气不再数拍子。看到叶霜画"下一代架构预研"→愣住→然后笑——"那种笑不是开心，是确认。确认她赌对了人。"→全书最秦岚的笑——不是开心，是确认。
- **张磊**：二十个感叹号→"跑通了？""嗯。"→全书最短的确认对话。借来的西装袖子长两厘米→全书最张磊的细节——不擅长正式场合但不在乎。
- **周成**：账本上写"8月28日，全部功能跑通。暑假结束前三天。"→第三次写非数字内容。画圈比之前都大→"圈的意思是：压力更大了。但他没有说。"→全书最周成的表达——不说，只画圈。

## 情绪技巧
- **毛细血管的疲惫书写**："不是熬夜的黑眼圈，是连续熬夜之后毛细血管破裂的那种青。"→用医学精度写疲惫——不是"她很累"，是"毛细血管破裂"。
- **手指温度的生理叙事**：陈默发现叶霜手指画图时凉/跑通后暖→用生理学写专注状态——全书最细腻的人物观察。
- **"可以了"的极简确认**：两个字→比"那就行"更收敛。全书最重的确认——不是宣布胜利，是确认完成。
- **沉默十五秒的震撼**：秦岚电话里安静十五秒（比上次多五秒）→用沉默时长写震撼程度——上次十秒，这次十五秒。
- **"你们赢了"的重量感**：沈灵发三个字→陈默没回→截图发407群→用"不回复"写"太重了不知道怎么回"。
- **结尾循环的确定感**："和昨天一样。和前天一样。和第一天一样。"→用重复写确定性——不是单调，是每一天都在做同一件对的事。
