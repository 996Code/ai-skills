# 情感猎手 — 第48章：孙正

## 情绪走向
- **好奇（秦岚带陌生人，白板前站十分钟）** → **压力（"好。但不够。"）** → **沉重（硅验证至少一千万）** → **确认（孙正说Jim Keller）** → **感动（孙正加入，条件：三个月审完）** → **燃烧（秦岚追加一千万，"赌中国的GPU能站起来"）** → **专注（孙正审三小时，叶霜重新推导）** → **日常（张磊七份盒饭，孙正二十年没在实验室吃过）** → **确定的安静（结尾"四杯咖啡"）

## 角色情感
- **孙正**：本章孙正的情感藏在"看十分钟"和"审三小时"里。站在白板前看十分钟不说话→二十年硬件工程师的审慎——不是随便看看，是一个箭头一个箭头地看。说"好。但不够。"→好=架构对，不够=缺硅验证——全书最精准的肯定+挑战。把叶霜比作Jim Keller→"不是恭维。是陈述。陈述一个做了二十年硬件的人的判断。"→全书最重的外部背书——用职业生涯做担保。加入条件：三个月审完每个模块→不是怕失败，是怕失败一次钱烧完——二十年经验教会他的审慎。审三小时后说"我知道Jim Keller为什么是Jim Keller了。因为他也是这样推导的。"→全书最燃的二次确认——看了推导过程之后再次确认判断。二十年没在实验室吃过盒饭→张磊说"那从今天起改"→全书最日常的接纳。
- **秦岚**：本章秦岚的情感藏在"追加一千万"和"赌中国的GPU能站起来"里。硅验证一千万→"我可以再融"→不是犹豫，是追加。说"赌中国的GPU能站起来"→语气不再数拍子→从商业投资到产业信念。结尾回头看白板→"四个人在同一个白板前面。各自的年龄加起来超过八十岁。但此刻他们都是十八岁。因为从头推导这件事——不管几岁，都是从零开始。"→全书最秦岚的观察——用年龄差写共同点。
- **叶霜**：本章叶霜的情感藏在"重新推导"里。孙正问"这条路径你们怎么解决的"→叶霜没回答→走到白板前拿起马克笔→从缓存层开始重新推导了一遍→每一步都有出处。不是解释，是展示——全书最叶霜的回应方式：不解释，推导给你看。孙正提优化建议→叶霜说"那就流片"→三个字——和"那就行""那就接""那就跑通"一样的句式。叶霜的词典里没有"如果"，只有"那就"。
- **陈默**：本章陈默的情感藏在"胃里"和"指尖"里。"硅验证"这个词像一块石头落在胃里→全书最精准的生理反应——不是"他震惊了"，是"胃里"。碰到键盘指尖凉的→"不是因为紧张。是因为312的空调还没修好。"→全书最陈默的自我解释——用客观原因掩盖情绪。

## 情绪技巧
- **"好。但不够。"的精准**：全书最精准的肯定+挑战——不是"好"就完了，是"好但不够"。二十年经验教会他的审慎。
- **Jim Keller的重量感**：孙正把叶霜和Jim Keller放在同一个句子里→全书最重的外部背书——不是"你很有天赋"，是"你和Jim Keller一样"。
- **胃里的石头**："这个词像一块石头落在胃里"→全书最精准的生理反应——用内脏写压力。
- **"那就流片"的确定感**：叶霜说三个字→和"那就行"一样的句式→全书最叶霜的回应——没有"如果"，只有"那就"。
- **"赌中国的GPU能站起来"的燃烧感**：秦岚追加一千万→不是追加投资，是追加信念——全书最燃的投资宣言。
- **盒饭的接纳**：张磊带七份盒饭→孙正二十年没在实验室吃过→"那从今天起改"→全书最日常的接纳——盒饭就是欢迎仪式。
