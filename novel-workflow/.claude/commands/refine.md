# 🔍 /refine — 审校（一致性+质量保证）

执笔完成后，做全书级检查。逐章审查在 `/write-chapter` 已经做了，审校做的是**跨章/全书级**问题。

## 审校五步

### 1. 一致性检查（全书级）
- **角色一致性**：性格/语言风格/能力前后统一？
- **时间线一致性**：时间/季节/年龄有矛盾？跑 `tail timeline.md` 对照
- **逻辑一致性**：因果链成立？有剧情漏洞？
- **世界观一致性**：规则前后矛盾？
- **信息差一致性**：角色是否"知道"了不该知道的事？

### 2. 伏笔闭环检查
```bash
# 看foreshadowing表，所有planned状态的伏笔是否都回收了
cat novels/*/planning/bible/foreshadowing.md | grep -E "planned|未收"
```
- 所有 major 伏笔必须回收或有明确留白理由
- 回收方式是否自然（不是突兀的"哦对了还有这个"）

### 3. 文风统一
- **Show Don't Tell 全书扫描**：搜索"感到/觉得/意识到/心中暗想/不禁/竟然"
- **高频意象频率**：同一种感官意象全文≤5次为佳
- **破折号频率**：每1000字≤8个
- **重复用词**：同一非锚定实词>8次需替换

### 4. 质量深检
```bash
python3 scripts/novel_check.py
```
看"质量深检"段，解决所有 ❌。

### 5. 精修删减
- 长篇：终稿比初稿短10%（去形容词/副词/解释性文字）
- Kill Your Darlings：不服务故事的优美段落，删

## 审校铁律
- **终审做全书级检查**——逐章审查解决不了跨卷问题
- **伏笔必须闭环**——结局前所有major伏笔回收
- **AI生成痕迹消除**——套话/过度描写/解释性文字要删

## 交付前必检
1. 无行号前缀、无Markdown格式残留
2. Show Don't Tell 扫描通过
3. 高频意象 ≤5次、破折号每1000字 ≤8个
4. 重复用词非锚定词 top20 无 >8次

需要完整检查清单时读 `skill/references/review-checklist.md`。
