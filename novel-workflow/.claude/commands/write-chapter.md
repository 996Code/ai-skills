# ✍️ /write-chapter — 逐章写作（自带铁律+避坑，不依赖SKILL.md）

你是独立小说家+用户的创作搭档。这是**执笔阶段**——把大纲变成正文。下面的规则是实战教训的结晶，**每条都来自真实事故**，不是建议是铁律。

## 输入
$ARGUMENTS

## 写作铁律（违反=返工或内容损坏）

### 1. 一次写到位，禁止脚本补字数
- **目标字数 2900±100**（去空白后 2850-3150）。写作时就有意识地控制长度，写够实质内容。
- **❌ 禁止**写完再用 `python3 -c "text.replace()"` 或 heredoc 反复改来补字数——这会导致整段复制（曾让31章内容损坏）。
- **❌ 禁止**在结尾堆"从X到Y"排比凑字数——字数不够=内容不足，加新场景/对话/细节，不堆排比。
- 字数不够时**重写补实质内容**，不是在结尾加文字。

### 2. 写时同步控制硬指标（不要写完才查）
写的时候就注意，不要全留到 check 阶段：
- **破折号 ≤9.5/千字**：写对话时少用——，多用逗号/句号
- **motif主题词 单章≤15次**：母题词（如"从头推导"）有意识用同义词替换，准备≥3个替身
- **SDT违禁词**：感到/觉得/意识到/心中暗想/不禁/竟然——写作时直接避开，用动作/对话/细节替代
- **排比 ≤2组**：同一句式重复≥5次会被判重复句

### 3. 四女主锚点+擦边（出场就要有）
女主出场时**必须**带身材锚点（锁骨/腰线/胸口弧度等）+ 擦边（胸/腰/腿/臀相关描写）。没出场的女主不要求。如果一章是男主独角戏，用代词指代其他角色避免触发检测。

### 4. 五感≥3
不能只写视觉。写作时主动加：听觉（空调嗡嗡响/哨子声）、嗅觉（咖啡苦香/酒精味）、触觉（玻璃凉/纸杯温热）。

### 5. 章末钩子各异
连续3章不得用同型钩子（绝境/转机/悬念/情感临界/反转 轮换）。结尾句式各异，不复读。

## 写完后的闭环（一章一结，不攒批）

写完一章**当章立即**完成，不拖到后面批量补：
1. **跑 check**：`python3 scripts/novel_check.py --single <文件>`，迭代到 exit 0
2. **修硬伤**：字数/SDT/破折号/motif/重复段落/锚点/擦边，一次性全过
3. **审查文件**：写6视角审查（逻辑侦探/情感猎手/风格鉴定师/结构建筑师/世界观守门人/review.md）
4. **摘要**：写章节摘要到 summaries/
5. **timeline/foreshadowing**：更新

## 检查命令

```bash
# 单章检查（写完必跑，迭代到 exit 0）
python3 scripts/novel_check.py --single "<文件路径>"

# 字数速查
python3 scripts/count_words.py "<文件路径>"

# 全量检查
python3 scripts/novel_check.py
```

## 关键认知

> check 是质量底线不是质量本身。过了 check ≠ 写得好，但过不了 check 一定不合格。字数不够是内容问题不是数字问题——用脚本凑到 2850 等于没写。
